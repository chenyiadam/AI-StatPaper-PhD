# stat-research · 科学问题与文献调研

## 硬性纪律

1. **AI 不编造文献**：凡涉及具体论文的陈述，只允许来自 (a) 作者提供的清单
   (b) 检索工具的真实返回。其余一律标注 `[待核验]`。
2. **先结构后内容**：做综述先建脉络图谱（lineage），再填内容；禁止时间流水账。
3. 问题必须落在"统计性质"上：相合性、速率、覆盖率先、识别性、稳健性——
   而不是"提高精度、增强鲁棒性"这类无内涵表述。

## 工作流

### A. 科学问题凝练（S1）
1. 用 `prompts/01-科学问题与选题.md` 的 **P01**：四步输出——复述确认 →
   现状拆解（精确到失效的统计机制）→ 3 个候选问题（张力/可解性/风险/难度）→
   降维打击测试。
2. 候选问题过 `checklists/C1-选题检查清单.md` A 组（逐项要具体回答）。
3. 用 **P02** 做研究空白定位（文献图谱差分）；查文献前后各跑一次。

### B. 文献检索（S2 前半）
1. 用 **P04** 生成检索方案：概念分解 → 关键词矩阵（行话/排除词）→
   每库布尔检索式 → 滚雪球计划 → 停止规则。
2. 执行时记录 PRISMA 式流水：检索式 → 命中数 → 筛选后数。
3. 检索源建议：Semantic Scholar API / OpenAlex / Google Scholar / arXiv
   （statistics 分区）；中文文献另查知网/万方。Web of Science/Scopus 有权限则优先。
4. 文献入库 Zotero + Better BibTeX；citekey 格式 `{firstAuthor}{year}{firstWord}`。

### C. 精读与笔记（S2 中段）
1. 每篇锚点文献用 **P05** 提取结构化笔记（模型设定/关键定理含假设与速率/
   证明技术链/实验设计/局限/与本文差分）。
2. AI 提取的定理内容**必须回 PDF 原文核对编号与条件**（引理引用错编号是
   AI 高频错误）。
3. 笔记存 `project/notes/`，命名 `作者年份-短词.md`，与 Zotero 附件关联。

### D. 综述段落（S2 后半）
1. 笔记 ≥ 10 篇后用 **P06** 写 Related work 初稿：按脉络组织、每段以差分
   句式收尾、citekey 占位待核验替换。
2. 所有引用逐条过 stat-citation-verify（三层核验）后才换真实 bibkey。

## 输出物（进入 S3 的条件）

- [ ] 一页问题陈述（科学问题 + 张力 + 空白地图）
- [ ] 检索流水记录（可复现）
- [ ] 文献笔记库（含每篇的"与本文差分"字段）
- [ ] refs.bib 骨架（全部条目过 C6 L1/L2 核验）
