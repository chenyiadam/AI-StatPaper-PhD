# stat-journal-fit · 期刊风格适配

## 硬性纪律

1. **改风格不改内容**：期刊适配只动表达、结构位置与格式；任何改动不得
   改变数学含义、结论强度与数字。三栏输出 + 内容改动风险清单（同 P20）。
2. **官网为准**：`journals/` 档案是惯例总结；页数、匿名、引用样式等
   硬要求投稿前必须对照期刊官网最新 Author Guidelines 核对。
3. **先剖析后动手**：没跑 P28 风格剖析就改写 = 换一种 AI 味。
4. **结构性删除是终检的裁决**：P29 迁移计划只移动不删除；
   删什么由作者在 P32 合规终检时逐条决定。

## 工作流（七步）

### 1. 选刊决策
贡献类型（理论/方法/应用）× `journals/` 档案"定位与偏好"逐条对表；
给出目标刊 + 2 个备选 + 一句话理由。犹豫时对 2–3 个候选各跑一次 P28。

### 2. 风格剖析（P28）
喂 2–3 篇该刊同方向论文 → 生成风格规则卡（结构/句式/理论呈现/实验呈现/
词汇/格式信号六类规则，每条带样本实例与适用动作）→ 末尾"本文差距表"。

### 3. 结构重排（P29）
初稿结构 → 该刊结构惯例：差异清单 → 迁移计划（正文/附录/补充材料/待删）
→ 编号映射表 → 重排骨架 → 断裂预检。
典型方向差异：JASA 证明下沉 appendix ↔ AoS 证明可留正文 ↔
Biometrika 全文压缩 30–50%。

### 4. 风格改写（P30）
逐段执行五道工序：去符号 AI 味（破折号插入语→从句/括号，保留数值
en-dash）→ 去词汇 AI 味（黑名单）→ 对齐该刊句式 → 对齐话语体系 →
拼写体系切换（Biometrika/JRSS-B 英式）。
每段三部分输出，作者逐段裁决。

### 5. 格式与引用迁移（P31）
模板/文档类替换 → 引用样式迁移（author-year ↔ 编号制映射规则）→
图表规格 → 前置件（标题页/致谢/数据声明）→ 匿名化扫描 → 验证命令清单
（编译 + 五个检查脚本 + supplement 独立编译）。

### 6. 该刊合规终检（P32）
档案专属改造清单逐项核对 + C8 三遍法 + C7 抽检 + 风格回归检查
（style_check 零告警、数字一致、贡献-定理-表号对应）→ 可提交/阻断清单。

### 7. Cover letter 适配
用 `templates/cover-letter.md` 产出该刊版：一句话贡献 + 引用该刊 scope
语言 + 无双投声明 + AI 使用一句披露 + 建议审稿人 3–5 位（文献池最近邻，
排除合作者）。

## 常见迁移陷阱

| 陷阱 | 说明 |
|---|---|
| author-year → 编号制 | SIM/中文核心/JMLR 是编号制；\citep 映射要做全，漏一处就出现 [?] |
| 英式/美式拼写 | Biometrika、JRSS-B 传统英式；全文必须一致 |
| 证明位置相反 | JASA 全下沉 vs AoS 部分正文化——同一篇投不同刊方向相反 |
| 术语体系 | 投 JMLR 要补 excess risk/sample complexity 桥接；投 Biometrics 要医学叙事 |
| 匿名政策 | 各刊不同且会变——每年核对一次，别沿用上次的记忆 |
| 中文文献 | 投中文核心必须补中文文献（知网），AI 文献池通常缺失 |
