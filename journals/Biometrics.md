# Biometrics

> 国际生物统计学会（IBS）旗舰。档案为惯例性总结，投稿前以官网为准。

## 定位与偏好

**发什么**：生物医学背景驱动的统计方法与应用——生物统计方法论
（必须从真实生物医学问题出发）、药械临床试验统计、流行病学数据分析、
组学数据分析。文章类型通常含 Methodology（方法+应用）、Case Studies、
Practice 等（分栏名称以官网为准）。

**不发什么**：与生物医学无关的方法论、没有真实健康/生物数据的
纯方法论文、对既有生物统计方法的微调。

## 结构惯例

- **临床/生物学动机前置**：Introduction 用医学语言讲问题（疾病、终点、
  决策），统计难点从医学需求中导出；统计学读者与医学读者都要能读。
- 方法节含**实施细节**：模型设定、估计、软件实现（说清用了什么 R 包/
  代码可得性）——Biometrics 读者是实践者，落地细节权重高。
- 报告规范：涉及临床试验/观察性研究/预测模型时，相应报告清单
  （CONSORT/STROBE/TRIPOD 系列）的遵循是审稿硬项。
- 章节惯例：Methods → Simulation → Application → Discussion，
  外加 Ethics/数据可得性声明。

## 语言与语气

- author-year 引用居多（以官网为准）；医学术语规范（疾病名、
  终点指标用领域标准译名/原名）。
- 措辞守医学生态：效应量给 CI；p 值报告规范；不写"证明有效"，
  写"结果支持/与…一致"；安全性/伦理表述到位。

## 理论呈现

- 方法论文需核心定理（相合性/渐近正态/检验性质），但呈现精简：
  主定理 + 条件合理性 + 证明在补充材料。
- 审稿重点常在：协变量缺失/测量误差/依时协变量等**医学数据现实**
  是否被处理——理论条件要经得起"真实数据长这样吗"的追问。

## 实验（模拟 + 数据）期望

- 模拟：场景要映射医学现实（脱落、协变量测量误差、事件数）；
  C3 清单全项 + size 校正。
- 真实数据：至少一个真实医学数据集；样本量/事件数/随访时间如实报告；
  与既有临床文献结论对表；伦理审批与知情同意声明必写。

## 格式硬要求（核对项）

- [ ] 模板：官网模板；结构化摘要与否以官网为准
- [ ] 报告清单：按研究类型勾选（CONSORT/STROBE/TRIPOD…）
- [ ] 伦理声明、临床试验注册号（如适用）
- [ ] 数据可得性 + 代码可得性声明
- [ ] 匿名要求以官网为准

## 该刊专属改造清单（初稿 → Biometrics 可投）

- [ ] Introduction 换医学叙事：疾病负担 → 临床决策 → 统计缺口

- [ ] 实施细节落地：软件、包版本、代码仓库
