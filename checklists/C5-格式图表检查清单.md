# C5 · 格式与图表检查清单

> 用法：定稿阶段。配合 `skills/stat-format-lint/SKILL.md` 与 `scripts/` 下的检查脚本。

## A. 期刊/学位格式

- [ ] A1. 模板与目标期刊一致（JASA/ARXIV/Biometrika/学位规范），页边距、行距、字号按指南
- [ ] A2. 标题页：作者全名、单位、通讯标注、致谢、资助号（基金号格式核对）
- [ ] A3. 摘要长度合规（多数统计刊 200 词上下）；关键词 3–6 个且来自期刊主题词表
- [ ] A4. 章节编号连续；\appendix 后编号切换 A/B/C 正确
- [ ] A5. 补充材料独立编译无引用断裂（supplement 里的 \ref 全部本地可解析）
- [ ] A6. 字体嵌入、图片分辨率 ≥ 300 dpi（矢量图优先 PDF/EPS）
- [ ] A7. 行号（投稿要求时）、匿名化（双盲：致谢、基金、仓库链接、作者自引改第三人称）

## B. 数学排版

- [ ] B1. 编号体系：公式 (1)…、定理 1…、假设 1…、图 1…、表 1… 各自独立且无重复
- [ ] B2. 所有引用用 \cref/\eqref，编译后无 "??"（跑两遍 latex + bibtex）
- [ ] B3. 行间公式后有标点（公式是句子的一部分）；where 从句定义新符号
- [ ] B4. 算子正体：\mathrm{Var}, \mathrm{Cov}, \mathbb{E}, \mathbb{P}；转置用 ^\top
- [ ] B5. 矩阵/向量加粗策略全文一致（小写粗体向量、大写粗体矩阵），或斜体但全文统一
- [ ] B6. 多行推导对齐点有意义（= 对齐）；超长行已拆分

## C. 表格（统计论文的三线表纪律）

- [ ] C1. 全部 booktabs 三线表，无竖线；数字按小数点对齐（siunitx 或手动）
- [ ] C2. 表头自含：每列指标含义、单位、最优判据；行是场景、列是方法（或反之）全文一致
- [ ] C3. 表注含：重复次数、指标定义缩写、加粗含义、种子或"详见复现包"
- [ ] C4. 位数遵循 three-digits rule；同一列小数位一致
- [ ] C5. 无"裁剪痕迹"：列宽不溢出版心；跨页表用 longtable 且表头重复

## D. 图

- [ ] D1. 每图自含 caption：看到图+caption 不看正文也能懂结论
- [ ] D2. 坐标轴标签完整（量、单位）；字体大小缩放后仍可读（≥ 8pt 等效）
- [ ] D3. 配色色盲友好（viridis 系或 Okabe-Ito）；黑白打印可辨（线型/标记点冗余编码）
- [ ] D4. 图内文字无位图锯齿；误差条/置信带含义在 caption 写明
- [ ] D5. 图与表不冗余重复：同一结果要么图要么表，或明确说"图是表的可视化"
- [ ] D6. 引用无缺失：每个 \begin{figure} 都被正文 \cref 引用（跑 `scripts/fig_table_check.py`）

## E. 参考文献

- [ ] E1. 样式与期刊一致（author-year vs 数字制）；natbib 命令统一（\citep/\citet 用对）
- [ ] E2. 所有条目字段完整：作者、年份、刊名（缩写统一或全称统一）、卷(期)、页码、DOI
- [ ] E3. arXiv 预印本：若已正式发表，替换为正式版（AI 引用预印本不放是常见错）
- [ ] E4. 无重复条目（同一论文两条 key）；大小写保护（{Bayesian}、{LASSO}）
- [ ] E5. 正文引用与 bib 双向一致：无 \cite{不存在} 也无未被引用的孤儿条目
      （跑 `scripts/citation_check.py`）
