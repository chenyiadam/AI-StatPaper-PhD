# C6 · 引用核验清单（三层核验）

> 用法：每一条**AI 参与**生成的引用都必须过三层核验。这是学术诚信的硬门槛。
> 配合 `skills/stat-citation-verify/SKILL.md`、`prompts/P07-引用核验.md`、`scripts/citation_check.py`。
> 背景数据：GPT-4o 在开放文献问答中 78%–90% 的情况下会出现引文幻觉（OpenScholar, Nature 2026）。
> **默认立场：AI 给出的每条文献引用，在人工核验通过前视为不存在。**

## L1 · 存在性核验（这条论文真的存在吗）

- [ ] 1.1 在 DOI 解析器（doi.org）验证 DOI 可解析且指向该题名
- [ ] 1.2 在 Google Scholar / Semantic Scholar / Crossref 检索题名能命中
- [ ] 1.3 作者真实存在：该作者确有此方向的其他工作（AI 常把两位真实作者缝合成一条引用）
- [ ] 1.4 卷(期)、页码与出版商页面逐字一致；arXiv 号格式正确（arXiv:XXXX.XXXXX）
- [ ] 1.5 警惕"看起来太合适"的文献：题名完美贴合你的论点，是幻觉引用的典型特征
- [ ] 1.6 中文文献在知网/万方二次确认（AI 幻觉中文文献率高，且常给出不存在的期刊卷期）

## L2 · 字段一致性核验（bib 条目和原文一致吗）

- [ ] 2.1 BibTeX 条目逐字段对照出版商官方 BibTeX 导出（不要用 AI 生成的条目直接入库）
- [ ] 2.2 作者列表完整且顺序正确（et al. 后是否真有更多作者）
- [ ] 2.3 期刊名全称/缩写与目标期刊要求一致；会议论文有地点与页码
- [ ] 2.4 年份正确（在线先发 vs 正式出版年常被 AI 混淆）
- [ ] 2.5 预印本已升级为正式版则替换；确未发表的预印本按期刊规则标注

## L3 · 内容支撑核验（原文真的支持你的论点吗）

- [ ] 3.1 打开 PDF，定位到你声称的结论所在章节；**转引不可接受**（不读原文就引用）
- [ ] 3.2 你的表述与原文结论方向一致（AI 高频问题：把"在某条件下"的结论引成无条件成立）
- [ ] 3.3 强度匹配：原文是"数值实验表明"，你写成了"理论上证明"——不行
- [ ] 3.4 引用的是最佳来源：同样结论若有更权威/更早的原始文献，改引原始文献
- [ ] 3.5 引用位置恰当：方法起源、定理出处、数据来源各自引对（定理出处错误是审稿人极反感项）
- [ ] 3.6 自引合理：与主题相关的自引可以，堆砌式自引删除

## 收尾

- [ ] S1. 运行 `scripts/citation_check.py`：正文 \cite 与 refs.bib 双向一致，无孤儿条目
- [ ] S2. 文献综述段落的"文献密度"合理：每段 3–8 篇且按方法脉络组织，非流水账
- [ ] S3. 全文引用分布健康：近 3 年文献 ≥ 1/3；目标期刊自引 2–4 篇（如确相关）
- [ ] S4. 核验记录留存：核验日期、核验人、原文 PDF 存放路径（建议 Zotero 附件 + 笔记）
