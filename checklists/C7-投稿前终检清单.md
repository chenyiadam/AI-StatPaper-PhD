# C7 · 投稿前终检清单（T-7 天倒计时版）

> 用法：计划投稿日前 7 天启动，每天一组。全部勾完再点 submit。
> 组合使用：先跑三个模拟审稿人（`prompts/P24`）→ 修复 →
> **过一遍 C8 定稿逐项检查清单（格式/引文/理论/语言/实验的逐项判定，
> 含一键脚本 `presubmit_check.py`）** → 再过本清单。

## Day −7：内容一致性

- [ ] 1.1 摘要中每个数字/结论与正文一致（摘要常在改稿后被遗忘）
- [ ] 1.2 Introduction 贡献列表 (i)(ii)(iii) 与正文章节顺序、定理编号一一对应
- [ ] 1.3 正文每个"将在 X 节证明/展示"的承诺已兑现（搜 forthcoming / will show）
- [ ] 1.4 理论中的 λ 阶、假设编号、速率常数在方法/模拟/附录三处一致
- [ ] 1.5 图表编号连续且全部被引用；附录引用 A.x 在主文可解析
- [ ] 1.6 复现包链接可用（匿名仓库投稿版单独准备）；README 一键命令实测通过

## Day −6：跑自动化检查

- [ ] 2.1 `citation_check.py` 通过（正文-文献库双向一致）
- [ ] 2.2 `notation_check.py` 通过（记号冲突/未定义告警清零或逐条裁决）
- [ ] 2.3 `fig_table_check.py` 通过（图表均被引用；caption 自含抽查）
- [ ] 2.4 `style_check.py` 处理完毕（AI 味符号与高频词：必改项清零、
      裁决项留痕——破折号插入语/黑名单词/连接词密度/中文 AI 短语）
- [ ] 2.5 LaTeX 编译零 error；warning 过目（overfull box 逐个处理）
- [ ] 2.6 拼写与语法检查（如 Writefull/LanguageTool），专有名词加入词典防误改

## Day −5：模拟审稿闭环

- [ ] 3.1 三个独立审稿人角色（统计理论/方法应用/表述规范）意见已汇总去重
- [ ] 3.2 每条意见分类：必须修 / 值得修 / 回信解释——修的已修，解释的已写进 rebuttal 草稿
- [ ] 3.3 "审稿人最可能攻击的一页"确认：假设节、size 校正、λ 选取、与 SOTA 对比公平性
- [ ] 3.4 封面信(Cover letter)写好：一句话贡献 + 为什么适合该刊 + 无一稿多投声明

## Day −3：伦理与合规

- [ ] 4.1 AI 使用披露完整（附录 D 模板逐条填写），符合目标期刊最新 AI 政策
- [ ] 4.2 所有引用过 C6 三层核验，核验记录在案
- [ ] 4.3 数据许可与知情同意（涉及人类数据）；敏感变量处理合规
- [ ] 4.4 利益冲突声明；基金致谢格式正确
- [ ] 4.5 作者列表与顺序经全体确认；ORCID 填写
