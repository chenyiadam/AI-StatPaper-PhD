# C4 · 学术语言与风格检查清单

> 用法：初稿完成后逐节过一遍。配合 `skills/stat-writing/SKILL.md`、`prompts/P20-P22`。
> 原则：AI 润色只改表达不动数学内容；每次润色 diff 后人工确认。

## A. 去 AI 味（AI 生成初稿的高频特征，逐条清除）

- [ ] A1. 禁用词已替换：delve, crucial, pivotal, comprehensive, utilize, leverage,
      moreover 堆叠, "It is worth noting that", "plays a vital role", "In recent years" 开头
- [ ] A2. 破除三段式模板腔：无 "Firstly/Secondly/Finally" 填充感；
      段落间靠逻辑衔接而非套路词
- [ ] A3. 删除空泛总结句（"In conclusion, our method is effective and promising"）
- [ ] A4. 每段有且只有一个论点；段首句是论点句而非背景复述
- [ ] A5. 名词化堆叠拆解（"the implementation of the utilization of…" → 直接动词）
- [ ] A6. AI 重复句式（连续多段同构："This method… This approach… This framework…"）改写
- [ ] A7. 语气校准：不夸大（novel/first 少用，用了必须能证明）、不卑微（we merely/only）
- [ ] A8. **符号层 AI 味**（跑 `scripts/style_check.py`，R1–R10 规则）：
      正文 em-dash 插入语（— / ---）清除（改从句/逗号/括号）；
      带空格 " -- " 清除；**数值区间 en-dash（1990--2000、页码）保留**——
      这是规范用法不是 AI 味；中文"——"一段至多一处；冒号引导句降密；
      连接词 Moreover/Furthermore 单文件 ≥3 次删减；"not only…but also" 拆解

## B. 统计论文语言规范

- [ ] B1. 时态：方法与结论一般现在时；实验实施过去时；图表解读现在时
- [ ] B2. "we" 的使用：可主动（We propose），但假设陈述用祈使/被动
      （Assume that… / Suppose that…），避免 "We assume" 进定理
- [ ] B3. 差分句式：提每一篇相关工作后必须接"whereas/in contrast our method…"，
      不允许并列堆文献
- [ ] B4. 术语全文统一：一个概念一个词（不混用 estimator/estimate；
      high-dimensional / high dimension 全文一致）
- [ ] B5. 缩写首次出现给全称，之后一律用缩写；摘要中独立计
- [ ] B6. 数字与单位规范；p 值报告格式统一（p = 0.032；p < 0.001 不写 p = 0.000）
- [ ] B7. 图表引用统一句式（Figure 1 shows… / As shown in Table 2…），不混用缩写 Fig.

## C. 中文学术写作（中文论文/学位论文适用）

- [ ] C1. 翻译腔清除："被进行"、"进行…的研究"、"基于…的基础上"
- [ ] C2. 统计译名规范（见 `docs/glossary-中英术语表.md`）：统一用"估计量/估计值"区分
      estimator/estimate、"显著"仅指统计显著等
- [ ] C3. 长句拆分：一句一个断言；"的"字链不超过 3 层
- [ ] C4. 中文论文标点全角、英文术语两侧空格规则全文一致

## D. 逻辑与论证

- [ ] D1. 每个论断要么有引用、要么有证明/实验、要么明确标注为猜想
- [ ] D2. Introduction 的每一条贡献在正文都有对应章节，且顺序一致
- [ ] D3. 段落链完整：Motivation → Gap → Method → Theory → Evidence → Implication
      在全文层面闭环
- [ ] D4. 讨论(Discussion)的每条局限诚实具体，且不推翻自己的核心主张
- [ ] D5. 让 AI 做一次"只读结构"重述（prompts/P27），若 AI 重述出的逻辑链与你的意图不符，
      说明行文有歧义
