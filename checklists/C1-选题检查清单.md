# C1 · 选题与科学问题检查清单

> 用法：开题/选题阶段，配合 `prompts/P01-P03` 与 `docs/02-阶段一-科学问题凝练.md`。
> 通过标准：每项都能写出一句**具体的**回答；写不出具体回答=还没过关。

## A. 科学问题的深度（博士水平的分水岭）

- [ ] A1. 用一句话说出核心科学问题，且该问题**不是**"把方法 A 用到数据 B 上"
- [ ] A2. 问题背后存在**统计理论张力**：如理论保证与实际性能的缺口、
      高维 vs 可解释、稳健 vs 有效的权衡——能说出这个张力是什么
- [ ] A3. 现有方法**为什么不能直接解决**：说出具体的统计性质缺陷
      （相合性失效？区间覆盖不足？速率次优？对分布假设敏感？）
- [ ] A4. "为什么是现在"：数据形态变化（更大 p、复杂依赖、异质性）或新理论工具出现，
      使问题变得可解/重要
- [ ] A5. 电梯测试：对非本方向的统计学者 90 秒讲清楚问题、难点与思路，
      对方至少能提出一个像样的问题

## B. 问题定位

- [ ] B1. 在文献图谱中标注：最近邻的 3-5 篇论文是什么，本文与每篇的**差分**一句话
- [ ] B2. 研究空白真实存在：最近 3 年顶刊/顶会没有人发表几乎相同的结果（检索已做）
- [ ] B3. 可行性预判：理论工具链存在（不是从零发明数学）、
      算法可写、模拟可跑、真实数据可得——每项有初步证据
- [ ] B4. 产出物可拆解：论文 = 方法 + 定理（≥2 个有意义的结果）+ 模拟 + 真实数据 + 开源包，
      每块都有明确的"成功标准"
- [ ] B5. 风险预案：若主定理只拿到次优速率/条件偏强，论文是否仍成立（B 方案）

## C. 贡献陈述（正文 Introduction 第 (ii) 段的原材料）

- [ ] C1. 三类贡献各一句：方法（机制）、理论（条件→结论，含速率）、计算/实证
- [ ] C2. 每条贡献**可指认**：能指出对应的目标函数编号、定理编号、表编号
- [ ] C3. 贡献排序有主次：本文最重的那张牌放在第一位
- [ ] C4. 反向检验：删掉本文某一条贡献后，论文是否还独立成立？
      若完全成立，说明这条贡献不是"本文的"
