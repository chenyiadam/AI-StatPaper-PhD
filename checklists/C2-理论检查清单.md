# C2 · 理论检查清单（证明逐项审查）

> 用法：把定理与证明喂给 AI 时，**连同本清单一起**作为审查框架（配合 `skills/stat-theory-check/SKILL.md` 与 `prompts/P10-证明逐行审查.md`）。
> 每一项必须人工确认「通过 / 不适用 / 待修」。AI 报告"通过"≠通过，AI 只负责定位嫌疑点，正确性由作者裁决。

## A. 假设与条件（Assumptions）

- [ ] A1. 每条假设**编号、命名、在定理中显式引用**（"在 Assumption 1–3 下"），不使用隐藏条件
- [ ] A2. 每条假设后有 Remark 讨论强弱：与文献假设对比（更弱/更强/等价）、能否放松
- [ ] A3. 假设之间**不矛盾**：如同时假设了分布与矩条件，检查相容性
- [ ] A4. 假设**在所研究场景下可验证或合理**（如对设计矩阵的条件，真实数据是否可能满足）
- [ ] A5. 维度条件自洽：$s\log p = o(n)$ / $\log p = o(n^c)$ 等在全文（正文+附录+模拟参数）中一致
- [ ] A6. 常数 $C, c, \delta$ 的定义不冲突、不循环依赖

## B. 引理与定理体系

- [ ] B1. 每个被引用的引理**确实已证**且编号正确（AI 高频错误：引用不存在的 Lemma 3.2）
- [ ] B2. 定理陈述中每个量**都已定义**（包括 $\beta_0$、$\lambda$、$s$、$C$）
- [ ] B3. 陈述自含：不看正文能否单独读懂定理（Big-O 里丢参数 $\delta$ 是高频错误）
- [ ] B4. 定理间的逻辑依赖是 DAG，无循环引用
- [ ] B5. 推论（Corollary）确实是定理的直接组合，未偷偷加强条件

## C. 证明内部（高频漏洞，AI 生成证明的重灾区）

- [ ] C1. **极限交换**：$\lim \sum \ne \sum \lim$、交换积分与极限（需控制收敛定理/单调收敛定理的验证）
- [ ] C2. **期望与概率**：$O_p$ 与 $o_p$ 的运算规则正确（$O_p(a)\cdot O_p(b)=O_p(ab)$；$o_p+o_p=o_p$；概率极限与期望不可随意交换）
- [ ] C3. **收敛模式不混淆**：依概率 / a.s. / $L^q$ 逐条对齐，未把一种收敛的结论用在另一种上
- [ ] C4. **"显然/易得/it is easy to see" 全部消除**：或展开、或替换为明确引理引用
- [ ] C5. **最大值与求和的控制**：$\max_j |X_j| \le (\sum_j X_j^q)^{1/q}$ 这类不等式的方向与常数正确
- [ ] C6. **事件分解**：好事件 $\mathcal{E}$ 上的界与 $\mathcal{E}^c$ 概率控制**两部分都在**（只证一半是高频漏洞）
- [ ] C7. **KKT 条件使用**：次梯度条件符号正确，$\lambda$ 的缩放与罚项归一化（$1/n$ 因子）匹配
- [ ] C8. **条件数与维数**：矩阵秩、特征值界的维数依赖正确（如 $p$ 依赖 $n$ 时未把 $p$ 当常数）
- [ ] C9. **测度论细节**：可测性、几乎处处 vs 逐点、条件期望的存在性（对博士生论文是审稿人常查点）
- [ ] C10. **渐近分布推导**：Delta 方法条件（可微性、$\sqrt{n}$ 尺度）、Slutsky 定理使用正确
- [ ] C11. **覆盖率/推断定理**：构造的区间方向正确（下界 ≤ 估计 ≤ 上界），覆盖率是对真参数而非估计
- [ ] C12. **常数追踪**：proof 中 $C_1, C_2, \ldots$ 未重复赋值；最终常数有限且与 $n,p$ 无关（或依赖已声明）
- [ ] C13. **上下界方向**：minimax 下界用 Fano/Le Cam 时，KL 散度计算与约化假设核对
- [ ] C14. **逐条引用核对**：证明中每个 "by [Ref, Theorem 2]" 拉出原文献核对**条件是否满足**（AI 常引用错编号、或引用条件更强的定理）

## D. 理论与方法的对应

- [ ] D1. 定理针对的估计量与式 (1) 定义的目标函数**是同一个**（AI 常写出不同罚项的混合体）
- [ ] D2. 理论中 $\lambda$ 的阶（如 $\sqrt{\log p/n}$）与算法实现/模拟中取值**一致**
- [ ] D3. 定理的稀疏假设与模拟 DGP 的 $s$ 设置一致
- [ ] D4. 正文声称的性质（如"预言性质"）在定理中**确有对应陈述**
- [ ] D5. 记号表（或首次定义处）与证明中的记号逐一一致（跑 `scripts/notation_check.py`）

## E. 表述规范

- [ ] E1. Proof 环境：以 $\square$ 结束；证明中断（leaving open）的地方显式标注
- [ ] E2. "Proof Sketch" 只放路线，全文证明在附录且一一对应
- [ ] E3. 数学排版：算子正体（$\mathrm{P}, \mathrm{E}$）、集合用 $\mathbb{}$、向量/矩阵加粗并全文一致
- [ ] E4. 定理陈述中不出现"我们"（We assume → Assume）；假设句式统一
- [ ] E5. 交叉引用全部用 `\cref`/`\eqref`，无手写编号（避免改稿错位）

## F. 审稿人视角终查（对应 prompts/P24-25）

- [ ] F1. 速率是否 minimax 最优？若非最优，正文是否有 remark 说明缺口与原因
- [ ] F2. 是否存在**已知反例**违反假设？（让 AI 专门构造反例：prompts/P12）
- [ ] F3. 理论是否"空转"：定理条件过强导致正文方法不满足？
- [ ] F4. 每条假设在模拟 DGP 中是否体现（审稿人常问：假设 2 在实验中成立吗）
