# C3 · 实验检查清单（模拟 + 真实数据）

> 用法：实验设计阶段对照一遍；投稿前对照一遍。配合 `skills/stat-simulation-audit/SKILL.md`、`prompts/P13-P16`。

## A. 模拟设计（Simulation Study）

- [ ] A1. **场景网格显式列出**：n × p × 信号强度 × 误差分布 × 方法，映射到论文 Table 的行列，不多不少
- [ ] A2. **DGP 与论文 5.1 节公式逐条对应**（脚本注释里写 DGP-1, DGP-2…，改一处同步改两处）
- [ ] A3. 误差分布至少含一个**非高斯/重尾**选项（证明稳健性）；
      如做推断，含构造检验的备择场景
- [ ] A4. 基准方法选择有依据：每篇相关文献至少一个代表 + 一个 naive 基准；
      基准方法的超参也调优（避免"稻草人对照"——审稿人一票否决点）
- [ ] A5. 重复次数 ≥ 500（推断类实验建议 ≥ 1000），蒙特卡洛标准误已报告或可算
- [ ] A6. **随机种子固定**且写入输出文件；种子规则化（如 seed = base + 1000*场景 + 重复序号）
- [ ] A7. 理论中 λ 的阶与实验 λ 的取值一致；另有数据驱动选取（CV）的对照
- [ ] A8. 计算时间可承受：预估总时长并写明（跑崩重来是博士延期常见原因）
- [ ] A9. 失败处理：某些场景方法不收敛时，记录失败率而非静默丢弃（NaN 是审稿人追问点）

## B. 评价指标

- [ ] B1. 估计类：RMSE / L2 误差 / L1 误差 / 相对误差，至少两种（对 $s$ 敏感度不同）
- [ ] B2. 模型选择类：TPR、FDR（或 Hamming 距离），高维场景必备
- [ ] B3. 推断类：**覆盖率**（对真参数）、区间长度、检验的实际 size 与 power——
      size 校正（nominal 5% 是否真在 5% 附近）是顶刊审稿必查
- [ ] B4. 预测类：样本外 MSE 用**独立的测试集**而非训练集残差
- [ ] B5. 全部指标在"同一次运行"中算出（避免改指标重跑导致场景漂移）

## C. 呈现

- [ ] C1. 表格遵循 **three-digits rule**：相对比较需要的位数即可，不堆 6 位小数
- [ ] C2. 最优值加粗；"最优"的判据在表注写明（每列独立 or 全表）
- [ ] C3. 每张表/图**正文中都有文字解读**，且解读的数字与表内一致（跑 `scripts/fig_table_check.py`）
- [ ] C4. 图：轴有标签与单位、图例完整、线型/灰度可区分（考虑色盲与黑白打印）、
      caption 自含并注明种子
- [ ] C5. 标准差呈现方式统一（均值±SD 或 MC 误差），全文一致
- [ ] C6. 正文展示代表性场景，全量结果放附录/补充材料，二者不矛盾

## D. 真实数据分析

- [ ] D1. **数据可得性声明**：公开数据给出获取方式与版本/哈希；受限数据说明获取流程
- [ ] D2. 预处理每步可复现（无手工改表）；缺失值处理有敏感性分析或明确理由
- [ ] D3. 样本量、协变量数、事件数（如适用）在表 1 报告
- [ ] D4. 结果解读**未超出数据支持范围**：不说"证明因果"除非识别假设成立并有对应假设编号
- [ ] D5. 与领域文献已有结果对比，差异有解释
- [ ] D6. 至少一个真实数据集；顶刊常期望两个（或一个数据集+外部佐证）
- [ ] D7. 敏感性分析：至少对超参/模型设定做一轮扰动
- [ ] D8. **预分析计划**（确证性分析适用）：主要分析/敏感性分析/排除规则
      在看到结局数据前书面固定（OSF 预登记或论文章程留档）；
      未预注册则按 P33 决策树写明理由，备审稿人问

## E. 复现包（Replication Package）

- [ ] E1. 目录按 TIER 4.0：`data/ code/ output/ docs/`，README 含一键运行命令
- [ ] E2. 环境锁定：`requirements.txt` / `renv.lock` / `environment.yml`，含 R/Python 版本号
- [ ] E3. 全部图表由脚本重新生成且数字与论文一致（核验方式写进 README）
- [ ] E4. 代码放入 Zenodo/OSF 获得 DOI 并在论文中引用
- [ ] E5. 敏感信息检查：API key、本地路径、个人身份信息已从代码与日志中清除
