# C8 · 定稿逐项检查清单（初稿完成 → 定稿投稿期间的必备检查）

> 定位：这是 C5（格式速查）与 C7（倒计时流程）之间的**逐项判定层**——
> 每条都是"可判定"的要求（要么过、要么不过、要么写明不适用理由），
> 按目标期刊逐一执行，直到全部清零。
> 自动化入口：`python scripts/presubmit_check.py main.tex appendix.tex supplement.tex --bib refs.bib`
> （编排四个既有脚本 + 本清单新增的确定性检查；输出项与本清单 A–E 组一一对应，
> 无法自动判定的条目由清单标注 [人工] 动作完成）。
> 修正原则：**自动检查定位问题，修正在对应提示词里做**（格式→P31；
> 语言→P20/P21；引文→P07；理论→P10）——确定性代码不直接改稿。

## 使用方法（三遍法）

1. **第一遍·机械**：跑 `presubmit_check.py`，处理全部 [自动] 项；
2. **第二遍·逐条**：按本清单 A→E 顺序过 [人工] 项，每条写 通过/不适用+理由；
3. **第三遍·回归**：改稿后重跑脚本 + 抽查被改动条目（防止改 A 破坏 B）。

## A. 期刊格式硬要求（以目标刊官网指南为唯一权威，`journals/` 档案为索引）

- [ ] A1 **逐项对照动作**：打开目标刊 Author Guidelines，把每条格式要求抄成
      自己的核对表（本清单 A2–A12 是通用骨架，期刊特有条目追加在末尾）
- [ ] A2 标题页：标题大小写风格（Title Case vs Sentence case 按刊）；作者
      全名拼写与**顺序**（=CRediT 确认过的顺序）；单位地址规范；通讯作者
      标注；ORCID [人工]
- [ ] A3 基金与致谢：基金号全称与格式（按刊模板）；致谢位置（脚注/独立节/
      标题页）；利益冲突声明按刊要求；匿名版删除致谢与基金 [人工]
- [ ] A4 摘要与关键词：摘要词数（统计刊常 150–250；**presubmit_check 自动
      计数**）；结构化与否；关键词数量（常 3–6，**自动计数**）与**排序规则**
      （字母序 / 重要性序，按刊）；摘要内是否允许引用与缩写 [自动+人工]
- [ ] A5 标题层级：一二级标题风格（编号 vs 无编号、大小写、Statement 式
      按刊）；**是否允许三级标题**（部分刊仅两级——`presubmit_check` 检测
      `\subsubsection` 使用并提示核对）；Discussion/Conclusion 是否必须
      [自动提示+人工]
- [ ] A6 正文格式：标点全文统一（牛津逗巴一致性、中文稿全角标点）；
      编号体系（公式/定理/图/表各自独立编号、`cleveref` 引用无手写编号
      ——**notation_check 自动**）；图表名称风格（Figure/Fig./图，全文一致）
      [自动+人工]
- [ ] A7 简写风格：每个缩写首次出现给全称一次；之后一律缩写；同一概念
      只有一个缩写（LASSO/lasso 大小写全文统一）；缩写不进标题（除非
      极通用如 MSE）[人工，术语表辅助]
- [ ] A8 图片：矢量优先（PDF/EPS）；位图 ≥300dpi；宽度按刊（单栏/双栏）；
      字号缩放后 ≥8pt 等效；色盲友好 + 黑白可辨（C5-D）[人工]
- [ ] A9 图表排版：**居中还是居左**按刊要求（figure 环境默认居中，需改时
      显式设置）；**表格中小数位数**：同一列小数位一致、遵循 three-digits
      rule（**presubmit_check 自动检测列内小数位不一致**）；表注完整
      （重复数/判据/缩写定义）[自动+人工]
- [ ] A10 禁止事项（AI/格式通病）：**正文破折号**（em-dash 插入语，数值区间
      en-dash 保留——style_check 自动）；**\item 滥用**（连续列表化、
      单条目列表、一段内超 3 个列表环境——**presubmit_check 自动**）；
      **比喻性引号**（"so-called X"式 scare quotes、正文直引号——
      **presubmit_check 自动检测直引号并提示改写**）[自动]
- [ ] A11 文中引文风格：author-year / 编号制按刊；\citep/\citet 分工正确；
      上标引用与否；引用句式多样化（避免每段都以 (Author, 2020) 结尾）
      [自动初查+人工]
- [ ] A12 文末参考文献：**排序规则**（引用序 / 字母序按刊）；期刊名全称与
      缩写统一；arXiv 已正式发表的替换为正式版；无孤儿条目、无缺失字段
      （**citation_check 自动**）[自动]

## B. 引文真实性收尾（对应 C6，定稿期最后一轮）

- [ ] B1 每条引用真实存在：L1 全过（DOI 可解析、Scholar 命中）[人工抽查+
      citation_check 形式层]
- [ ] B2 **不确定的文献：替换或删除**——本清单的铁律是"宁可少引，不可存疑"：
      任何一条 L1/L3 拿不准的文献，或替换为确定存在的等价文献，或直接删除
      并微调句子；**禁止带着"应该存在吧"的引用投稿** [人工]
- [ ] B3 正文对引文的描述准确：转述与原文结论方向、强度、条件一致
      （L3 三种失配逐一过）[人工]
- [ ] B4 正文-bib 双向一致（**citation_check 自动**）[自动]

## C. 内容完整性（理论核对）

- [ ] C1 理论推导：过 C2 全清单 + 按 `docs/11` §8.6 目标刊档位校准检查
      强度（L3 逐行验算级需人工重算关键不等式）[人工]
- [ ] C2 **正文-附录一一对应**：正文每个带编号的定理/引理/命题/推论，
      都有对应证明位置（正文内或附录 "Proof of Theorem X"）——
      **presubmit_check 自动比对定理标签在附录的出现情况**，输出
      "附录无对应"清单供人工裁决（部分结果可能正文自证，属合法，
      但必须逐条确认）[自动初查+人工裁决]
- [ ] C3 附录完整、详细、准确：引理链完整（被引用的中间结果全部先证）；
      无"显然"残留（**notation_check 自动扫描**）；常数编号不重用；
      记号与正文一致（**notation_check 自动**）[自动+人工]
- [ ] C4 定理/命题/引理**不滥用**：环境用对（主结果→theorem，辅助→lemma，
      直接推论→corollary，评注→remark）；数量合理（**presubmit_check
      统计各环境数量分布**，如 corollary 多于 theorem 属异常信号）；
      每个编号结果都被正文引用（**notation_check 自动**）[自动统计+人工]

## D. 语言与逻辑

- [ ] D1 **句间自然衔接**：每句与前句有可指认的逻辑关系（递进/转折/因果/
      例证）；连接词密度正常（Moreover 连用 ≤3——style_check 自动）；
      通读检查"跳句"（两句间需要读者自行脑补桥梁的）[自动+人工通读]
- [ ] D2 **每段有中心思想**：段首句是论点句；一段只说一件事；删除不服务
      于任何论点的句子 [人工]
- [ ] D3 **禁止元说明/元数据语句**：逐段预告（"In this section we will
      discuss..."——节首一句 roadmap 是惯例，逐段/逐句预告是元说明）；
      "As mentioned above / as discussed earlier" 滥用；"It should be
      noted"；未完成的承诺（"we will show" 全文检索——**presubmit_check
      自动检测元说明模式与承诺句**）[自动+人工]
- [ ] D4 过渡与解释存在：每个定理后有解读（含义/速率意义）；每个公式后
      有符号解释；每个图表在正文中被文字解读（**fig_table_check 自动**
      引用闭环；解读文字 [人工]）[自动+人工]
- [ ] D5 语言准确：时态、术语、语气过 C4；estimator/estimate 等术语表
      硬约定 [人工+术语表]

## E. 实验对齐（实验是否体现了论文与算法的思想目的）

- [ ] E1 **实验目的映射表**（本清单核心产出）：逐项列出
      `实验项（场景/指标/数据集） → 支撑的论文主张 → 对应定理或论点编号`；
      表中任何一行填不出"对应主张"的实验是无效实验（删或补主张）；
      任何一条 Introduction 贡献没有实验行支撑的是空头贡献（补实验或
      改贡献表述）[人工]
- [ ] E2 **算法实现与论文一致**：代码中的目标函数/损失/罚项与式 (1) 逐项
      对照；λ 与超参取值与理论阶一致；算法伪代码与实现一致
      （stat-simulation-audit P14 已查，定稿期复查改动未破坏一致性）[人工]
- [ ] E3 **实验"演给定理看"**：边界场景在（定理条件刚满足/刚违反）；
      推断类实验含 size 校正与覆盖率（对真参数）；重尾/非高斯场景在
      [人工，对照 P13 网格]
- [ ] E4 结果解读与数字对账：论文正文全部数字 ↔ 实验输出 ±0.01；
      模拟结论与理论预期不一致处已如实写出并解释 [人工+数字-单元格表]
- [ ] E5 组件证据（算法思想的体现）：消融/敏感性分析拆解出方法各组件的
      贡献（证明"是机制 X 在起作用"而非黑箱取胜）[人工]
