## 7.0 期刊风格适配（先于一切格式工作）

同一篇论文投不同期刊的正确长相完全不同（证明位置、贡献呈现、引用样式、
话语体系）。先跑 `skills/stat-journal-fit` 七步工作流：

```
选刊决策 → P28 风格剖析（该刊样本→风格规则卡）→ P29 结构重排
→ P30 风格改写（含符号 AI 味清除）→ P31 格式与引用迁移
→ P32 该刊合规终检 → cover letter（templates/cover-letter.md）
```

典型差异（详见 `journals/` 各档案）：
- **证明位置相反**：JASA 全部下沉 appendix ↔ AoS 证明可留正文；
- **篇幅**：Biometrika 压缩 30–50% ↔ JMLR 宽松；
- **引用样式**：统计刊 author-year ↔ 医学刊/中文刊/ML 刊编号制；
- **数据故事**：JRSS-B/AOAS 要应用叙事 ↔ AoS 只要理论；
- **拼写**：Biometrika/JRSS-B 英式传统。

铁律：改风格不改内容；官网最新指南 > 档案。

## 机械检查（每次定稿前必跑；推荐先跑一键编排器）

```bash
# 一键编排器：聚合下列四脚本 + C8 新增八项检查（摘要词数/关键词数/
# 三级标题/列表滥用/直引号/元说明/定理环境分布/正文-附录证明对应/
# 表格列内小数位）
python scripts/presubmit_check.py main.tex appendix.tex supplement.tex --bib refs.bib

# —— 单独运行各脚本 ——

python scripts/citation_check.py main.tex appendix.tex --bib refs.bib
python scripts/notation_check.py main.tex appendix.tex supplement.tex
python scripts/fig_table_check.py main.tex appendix.tex
python scripts/style_check.py main.tex appendix.tex
```

| 脚本 | 查什么 | 对应清单 |
|---|---|---|
| citation_check | 正文-bib 双向一致、孤儿条目、必填字段、TODO 残留、journal+arXiv 并存 | C6 收尾 |
| notation_check | 重复 label/宏、悬空引用、未引用定理、**"显然"扫描**、TODO/AICHECK/REFCHECK 残留 | C2-E、C4 |
| fig_table_check | 图表引用闭环、caption 自含、三线表纪律（\hline→toprule、竖线）、手写编号 | C3-C、C5-C/D |
| style_check | **AI 味符号与用词**：em-dash 插入语（数值区间 en-dash 保留）、30+ 黑名单词、连接词密度、not only-but also、中文"——"与 AI 短语（R1–R10） | C4-A、P21 |
| presubmit_check | 上述四者 + C8 的 [自动] 项（N1–N8），退出码汇总 | **C8 全部** |

退出码非 0 = 有问题；逐条处理直到通过或逐条记录"不修理由"。
[自动] 项之外，C8 的 [人工] 项（标题页/基金/图表对齐/引文描述准确性/
实验目的映射等）按 **C8 三遍法**走完——这是 S7 门禁的一部分。

## 统计论文格式速查

1. **定理体系**：`\newtheorem` 集中在导言区；assumption 单独编号；
   交叉引用一律 `\cref/\eqref`（`cleveref`），禁手写编号。
2. **三线表**：booktabs；无竖线；小数点对齐（siunitx）；表注含
   重复次数/判据/缩写定义/three-digits 说明。
3. **数学排版**：算子正体、$\mathbb{E},\mathbb{P}$、转置 `^\top`；
   行间公式是句子的一部分（后跟标点 + where 从句）。
4. **图**：矢量 PDF；Okabe-Ito 或 viridis；线型/标记冗余编码
   （黑白打印可辨）；轴标签带单位；caption 自含。
5. **引用样式**：author-year（natbib，\citep/\citet 分工）；
   arXiv 已正式发表者替换为正式版。

## 格式层通用细则（P31 的补充，风格层已由 7.0 处理）

1. 基于本仓库 `templates/latex/main.tex`（JASA 风格）写作，内容与格式分离，
   风格适配只动 `journals/` 档案中列出的层面；
2. 引用样式与文档类迁移按 P31 工单执行（author-year ↔ 编号制的映射
   是最大工作量项）；
3. 页数超限迁移：证明 → 附录；次要表 → 补充材料（独立编译自含）；
4. 双盲版单独分支：致谢/基金/自引第三人称/匿名复现仓库；
5. 行号包按投稿系统要求加。

## 投稿倒计时（C7 全文版）

- **Day −7 内容一致性**：摘要数字、贡献-正文对应、承诺兑现、理论三处一致
  （λ 阶、假设编号、速率）、复现包链接实测。
- **Day −6 自动化**：`presubmit_check.py` 零阻断（汇总五个脚本）；编译零 error；warning 过目；拼写语法。
- **Day −5 模拟闭环**：第二轮审稿模拟的必修项全清；cover letter 成稿。
- **Day −3 伦理合规**：AI 使用披露（`docs/09`）逐条填写；C6 核验记录在案；
  数据许可；利益冲突；作者顺序确认。
- **Day −1 提交包**：全部文件按系统清单上传；下载回执 PDF 再目检；
  终稿 git tag 归档。
