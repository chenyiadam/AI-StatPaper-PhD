# 02 · 阶段一：科学问题凝练

> 配套：`prompts/01-科学问题与选题.md`（P01–P03）· `checklists/C1-选题检查清单.md`
> 本阶段目标：把一个模糊的研究冲动，逼成一个**落在统计性质上、有理论张力、
> 可指认贡献**的博士级科学问题。

## 为什么这一阶段最难也最重要

AI 时代写论文的瓶颈从"把话说全"转移到了"问对问题"。AI 可以流畅地生成
"把方法 A 应用到数据 B"式的应用题——这类问题在评审眼里是硕士题。
博士级问题的分水岭在于（C1-A 组）：

1. **统计性质张力**：问题背后有两个统计需求在打架——
   理论保证 vs 实际性能、高维 vs 可解释、稳健 vs 有效、估计 vs 推断。
2. **失效机制精确**：能说出常规方法失效的*具体统计机制*
   （相合性失效？覆盖率先塌缩？速率次优？对分布假设敏感？维数在哪一步爆炸？），
   而不是"效果不好"。
3. **可定理化**：问题能对应到"一个定理可以陈述的对象"。

## 操作流程

```
白话冲动 → P01 凝练（四步）→ C1-A 检验 → P02 空白定位
        → 粗查文献证伪 → P03 贡献草案 → C1-B/C 可行性与风险 → 立项
```

### 第 1 步：P01 凝练（四步输出）
把 200 字白话描述喂给 P01，得到：复述确认 → 现状拆解（精确到失效机制）
→ 3 个候选问题（张力/可解性/风险/难度）→ 降维打击测试（哪些部分
被砍掉后它就沦为硕士题——被砍掉的部分正是博士级的所在）。

### 第 2 步：C1-A 检验
每个候选问题过 `checklists/C1` A 组。**写不出具体回答 = 没过关**，
AI 会替你写通顺的话——不许它代写这一步。

### 第 3 步：P02 空白定位 + 文献初筛
P02 输出空白地图（脉络 × 维度矩阵）。随后**粗查文献证伪**：
Semantic Scholar / Google Scholar / arXiv 检索候选问题的关键词组合，
近三年无近似工作才继续（检索式记录下来，S2 阶段复用）。
AI 说"没人做过"不可信——必须自己查。

### 第 4 步：P03 贡献草案与可行性
贡献三条（方法/理论/计算）+ 每条反向删除测试 + B 方案
（若主定理只拿到次优速率，论文是否仍成立）。风险预案现在写，
不是投稿前写。

## 本阶段 AI 的用法边界

- **AI 擅长**：把直觉逼成精确表述、列出候选张力、做降维测试、
  挑战你的问题陈述。
- **AI 不可信**：断言"没人做过 X"（会编造或遗漏）、评估"novelty"
  （它对文献的记忆不可靠）。novelty 判断必须来自你自己跑的检索。
- **作者独占**：最终问题选择——这是品味，不是计算。

## 产出物模板

一页问题陈述，固定栏目：

```markdown
# 科学问题：{{一句话，主语是统计对象，谓语是统计性质}}
## 张力：{{哪两个统计需求在打架}}
## 失效机制：{{常规方法失效的具体机制，精确到统计性质}}
## 为什么是现在：{{数据形态变化 / 新工具}}
## 候选定理对象：{{期望的主定理形态（条件→结论→速率）}}
## 最近邻与差分：{{3-5 篇 + 各一句话差分}}
## B 方案：{{理论打折时论文还剩什么}}
```
