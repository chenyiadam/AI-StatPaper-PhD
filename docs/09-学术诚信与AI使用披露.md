# 09 · 学术诚信与 AI 使用披露

> 本项目的底线立场：**AI 是加速器，不是代笔人。** 用 AI 做到博士水平的前提
> 恰恰是你自己达到了能核验 AI 的水平。本页给出可执行的诚信规范。

## 红线（任何时候不可越过）

1. **引用必须逐条核验**（C6 三层）——AI 引文幻觉率 78%–90%（GPT-4o 类模型，
   OpenScholar/Nature 2026）。编造引用是最严重的学术不端之一，
   一条即可撤稿。
2. **数据不可伪造**：AI 不得生成"应该会出现"的实验数字；一切数字来自
   真实运行（数字对账规则：正文数字 ↔ 实验输出 ±0.01）。
3. **理论正确性由人裁决**：AI 审查只能定位嫌疑点；证明的正确性
   由作者负责。让 AI"写个证明"然后直接放进去 = 引用幻觉的定理版。
4. **AI 不署名**：各期刊与出版商共识（COPE、ICMJE、主要科技出版商联合原则）：
   AI 不满足作者资格（无法承担责任、无法声明利益冲突）。
5. **遵守目标期刊政策**：投稿前读该刊最新的 AI 使用政策（变化很快）；
   披露格式按其要求。

## 披露什么（默认模板见 `templates/latex/appendix.tex` D 节）

| 使用环节 | 披露要点 |
|---|---|
| 文献检索 | 工具名 + "所有引用经人工逐条核对原文" |
| 代码 | AI 用于解释/测试生成；数值结果由作者本地运行复核（种子与环境公开） |
| 理论 | 定理与证明由作者提出验证；AI 用于一致性检查，不作为正确性保证 |
| 语言润色 | 工具名 + "不改变数学内容与结论" |
| 未使用项 | 明确写"AI 未被用于：数据生成、结果编造、未经核验的引用插入" |

**操作建议**：留痕即披露——`project/ai_logs/` 存各阶段对话存档；
披露内容从留痕生成，不靠回忆。披露宁可过度具体，不可模糊泛化
（"本文使用了 AI 工具"不是合格的披露）。

## 人的不可替代清单（自查：这些是不是你做的）

- [ ] 科学问题的选择与品味（AI 可以逼问，不能替你选）
- [ ] 定理证明路线与关键不等式（AI 起草细节、执行攻击，想法是你的）
- [ ] 对每个检查清单项的最终裁决（C1–C7 全部"人工确认"栏）
- [ ] 每条引用的 L3 内容支撑核验（打开原文 PDF）
- [ ] 实验数字的溯源确认（数字-单元格对照表）
- [ ] 对论文每一句话的理解与辩护能力（答辩/审稿回复时你会被问到）

## 数据与许可

- 数据许可覆盖研究用途；人类数据有伦理审批与知情同意说明。
- 复现包中清除 API key、本地路径、个人身份信息（C3-E5）。
- 使用的开源代码遵守其许可证（本项目 MIT；注意你引入的工具：
  ARS 是 CC-BY-NC 非商业，Open Academic Paper Gen 是 AGPL-3.0 衍生需开源）。

## 一段写给焦虑者的话

用 AI 写论文不丢人，丢人的是被 AI 骗（引用幻觉、证明跳步、数字编造）
而不自知。本项目的全部清单、脚本、双模型交叉、门禁机制，
本质上是把"不自知"变成"有记录的裁决"。核验工作量是真实的——
但这正是博士论文水平的含义。
