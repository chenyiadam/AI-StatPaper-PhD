## 8.0 全生命周期地图（S0–S8）

```
S0 立项（章程/数据/算力/作者分工/预注册决策）──▶ S1..S7（见 docs/01）
──▶ S8 投稿执行（系统操作/预印本）──▶ 等待与催稿 ──▶ 决策三路
──▶ 修改循环（回 S5/S6）或 ──▶ 校样 ──▶ 版权/OA ──▶ 上线 ──▶ 宣传与勘误
```

## 8.1 S0 立项：把"会不会翻车"的问题提前回答（P33）

七个必须书面回答的问题：里程碑倒排（含 ≥25% 缓冲）、**数据可得性预检**
（申请周期、伦理审批、备选数据集）、算力预算、**作者分工协议**
（CRediT 逐人 + 作者顺序书面确认）、**预注册决策**（Registered Reports /
预分析计划 PAP / 明确的不预注册理由）、文献监控计划、风险登记册。
合作项目里，作者顺序在立项日确认比在投稿周争论便宜一百倍。

## 8.2 投稿执行（P34–P35）

- **投稿系统**（Editorial Manager / ScholarOne）：文件预检 → 强制字段映射
  （数据声明/基金/利益冲突/AI 披露/CRediT）→ 技术性一票否决点 →
  上传顺序 → receipt PDF 目检 → 记录**投稿编号与日期**（催稿的凭证）。
- **预印本**：政策核对 → **arXiv endorsement 门槛**（首投者需同分类学者
  背书，提前数周办）→ 版本同步纪律 → 许可证联动。

## 8.3 等待期：状态解码与催稿礼仪（P36）

常见系统状态解码（Editorial Manager 系）：

| 状态 | 含义 | 正常时长 | 何时该问 |
|---|---|---|---|
| Submitted / With Editor | 编辑初筛 | 2–6 周 | 超 6 周且无 desk decision → 问一次 |
| Under Review | 外审中 | 3–6 个月（以该刊自述为准） | 超自述周期 + 4 周 → 问一次 |
| Required Reviews Completed | 意见收齐待决策 | 2–8 周 | 停超 8 周 → 可礼貌询问 |
| Decision in Process | 编辑写决定 | 1–4 周 | 耐心等 |
| With Editor（修回后） | 编辑看修改稿 | 视修改幅度 | 修回后 2–3 个月无音讯 → 问一次 |

催稿三律：**低频**（同稿两次询问间隔 ≥ 6 周）、**对编辑不对审稿人**、
**只讲事实**（编号/日期/超期时长）。模板见 P36。

## 8.4 决策三路（P37）

- **修改**：意见聚合（P25）→ 回复信（P26）→ 修改稿照走 S5/S6 纪律
  （"小修"不免除 style_check 与数字对账）；需要延期就一次申请到位。
  **每轮修改前重跑文献保鲜检索**（审稿常耗时一年，文献不等人）。
- **拒稿**：24 小时冷静期 → 意见分诊（技术错误/范围错配/误读）→
  申诉仅在能证明事实性误判时考虑（默认路径是修改后转投）→
  用 journals/ 重新选刊 → 预印本同步。
- **录用**：进 8.5 校样流程。

## 8.5 校样、版权与发表后（P38）

校样只改错排不改内容；Author Query 简短精确；返回时限 48–72 小时。
版权/OA/license 决策对照期刊政策。发表后 30 天：克制的宣传清单、
引用监控、发现实质错误立即走 errata——**主动勘误是声誉资产，
被动撤稿是声誉负债**。

## 8.6 各刊理论严谨性检查强度校准（供 P10 / stat-theory-check 定档）

同一份证明，不同期刊的"合格线"不同。跑 P10 前，按目标刊设定检查档位：

| 档位 | 期刊 | AI 检查配置 | 人工必做 |
|---|---|---|---|
| **L3 逐行验算级** | Annals of Statistics、Biometrika | P10 双模型 + 第二轮"专验常数与维数"专项 + C2 全部 30+ 项 | 逐行重算关键不等式；引用的外部定理逐条拉原文核对条件 |
| **L2 保证级** | JASA、JRSS-B | P10 双模型 + 假设-使用对照 + 速率定位必答 | 主定理人工重走一遍；假设 Remark 完整 |
| **L1 合理级** | AOAS、Biometrics、SIM、JMLR | P10 单模型两轮 + Q1/Q3/Q5 三类重点 | 主定理陈述与条件合理性检查；数值结论核对 |
| **L1' 中文规范级** | 中文核心刊 | L1 档 + 术语表一致性检查 | 中文译名统一（术语表）、记号不翻译约定 |

配套动作：把目标刊的档位写进 P28 风格规则卡；转投换刊时**重新校准档位**
（从 JASA 转投 AoS，检查强度必须升档）。

## 8.7 门禁（进入 S8 与结束 S8）

进 S8（投稿日）：C7 全清 + 四脚本零阻断 + 投稿包按 P34 预检通过。
S8 出口（论文上线）：校样返回 + 版权/OA 完成 + 复现包 DOI 可解析 +
勘误渠道知晓。此后项目沉淀：把本轮审稿暴露的新问题写回 C2/C3
（CONTRIBUTING）。
