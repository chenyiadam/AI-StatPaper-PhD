# 03 · 阶段二：文献调研与综述

> 配套：`prompts/02-文献调研与引用.md`（P04–P07）· `checklists/C6-引用核验清单.md`
> · `skills/stat-citation-verify/SKILL.md`
> 本阶段目标：建立**可复现**的检索流水、**结构化**的笔记库、
> **全部核验**的文献池——综述是从这三样东西里长出来的，不是"让 AI 写一篇综述"。

## 三条支柱

### 支柱 1 · 检索流水（可复现性）
P04 生成检索方案：概念分解 → 关键词矩阵（行话/同义/缩写/排除词）→
各库布尔检索式 → 滚雪球计划（锚点文献向前向后扩展）→ 停止规则。
执行时按 PRISMA 风格记录：

```
数据库 | 检索式 | 命中数 | 去重后 | 题名筛后 | 摘要筛后 | 精读数
```

审稿人问"你怎么找文献的"，这条流水就是答案。

### 支柱 2 · 结构化笔记（30 篇精读的标准）
每篇用 P05 提取：一句话定位 → 模型设定 → 核心方法 → **关键定理
（逐条抄假设与结论，含速率）** → 证明技术链 → 实验设计 → 局限
（作者说的 + 你发现的）→ **与本文差分**。
AI 提取的定理内容必须回 PDF 核对编号与条件——AI 引错定理编号是高频错误，
这个错误一旦进入你的综述，会以引用链的形式放大。

### 支柱 3 · 文献池与核验（引用纪律的源头）
1. Zotero + Better BibTeX 管理；citekey：`{firstAuthor}{year}{firstWord}`。
2. 任何进入 refs.bib 的条目过 C6 的 L1（存在性）/ L2（字段）核验；
   L3（内容支撑）在引用进正文时逐条做。
3. `scripts/citation_check.py` 兜底：双向一致、字段完整、孤儿条目。

## 综述段落怎么写（P06）

- **按脉络组织**（lineage），不按时间流水账：每条脉络一段——演化逻辑
  → 代表工作 → 隐含假设/未解决问题 → 与本文差分（whereas 句式）。
- 密度：每段 3–8 篇；总长 ≤ 1 页。
- 差分句库轮换：whereas / in contrast / differs from / complementing these。
- **每条引用承担明确论证功能**（背景/对比/缺口/方法来源），
  纯装饰性引用删掉。

## AI 在文献阶段的正确用法（借鉴 OpenScholar 思想）

OpenScholar 的设计值得全文借用，即使不用它的模型：

1. **先检索后生成**：让 AI 写任何涉及文献的段落前，先把你筛过的笔记喂进去；
   无检索的"综述生成"= 幻觉生成器。
2. **Self-Feedback 循环**：初稿 → AI 自生成 ≤ 3 条改进反馈（按优先级）→
   逐条修订 → 引文核验（citation-worthy statements 是否都有引用支撑）。
   这个循环比"一次生成"质量高一个档次。
3. **引用核验的两个量化维度**（可自查）：
   - Citation Recall：该带引用的陈述是否都带了、引用是否支撑；
   - Citation Precision：每条引用是否支撑其陈述、删掉它是否伤及其余。
4. **meta-filtering 思想**：检索结果每篇论文最多取 3 个最相关段落
   进上下文——喂给 AI 的材料要精选，不是越多越好。
