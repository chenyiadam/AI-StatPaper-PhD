# 复现包目录模板（TIER 4.0 风格）

> 把本文件复制到你的论文工作区作为 `README.md` 骨架，逐项填充。
> 配套：`checklists/C3-实验检查清单.md` E 组；投稿前 C7-1.6 实测一键命令。

```
replication-package/
├── README.md                ← 本文件：运行说明 + 数字核对方法
├── data/
│   ├── raw/                 原始数据（或获取脚本 + 哈希校验 SHA256）
│   ├── processed/           预处理产物（由 code/00_clean 重新生成）
│   └── README.md            每个文件的来源、许可、变量字典
├── code/
│   ├── 00_clean.R|py        预处理（从 raw 到 processed，无手工步骤）
│   ├── 01_simulation.R|py   模拟实验（种子固定；对应论文 §5）
│   ├── 02_real_analysis.R|py 真实数据分析（对应论文 §6）
│   ├── 03_figures_tables.R|py 全部图表生成（对应论文图 1-4、表 1-3）
│   ├── methods/             本文方法的核心实现（独立于实验脚本）
│   └── tests/               单元测试（方法实现的正确性检查）
├── output/
│   ├── figures/             生成的图（PDF 矢量）
│   ├── tables/              生成的表（.tex / .csv）
│   └── sim_results.csv      模拟原始汇总（带种子与日期）
├── environment.yml / renv.lock / requirements.txt   环境锁定（含解释器版本）
└── ai_logs/                 （可选）各阶段 AI 辅助记录，用于披露
```

## README 骨架（填充后随包发布）

```markdown
# Replication Package: {{论文标题}}
{{作者}} · {{年份}} · DOI: {{Zenodo/OSF DOI}}

## 环境
- R {{4.x}}（renv.lock）/ Python {{3.x}}（requirements.txt）
- 硬件：{{如：8 核 CPU，无需 GPU}}；预计总运行时长：{{X 小时}}

## 一键复现

（全部对应关系见论文附录 D 或本包 numbers_map.csv）

## 许可与致谢
数据：{{来源与许可}}；代码：MIT；AI 辅助披露见论文附录 {{D}}。
```

## 纪律（对照 C3-E）

1. **无手工步骤**：从 raw 到 output 的每一步都可由 code/ 重建；
   敢于写"删除 output/ 后一键全部重建"。
2. **数字可溯源**：论文每个数字 ↔ 包内文件单元格（±0.01 容差），
   对应关系放进 numbers_map.csv。
3. **环境锁定**：审稿人机器 ≠ 你的机器；锁定到版本号。
4. **敏感信息清零**：API key、本地绝对路径、个人身份信息；
   发布前 `findstr /s /i "C:\Users api_key password" code\` 扫一遍。
5. **DOI 发布**：Zenodo / OSF 上传后取 DOI，写进论文脚注与摘要页。
