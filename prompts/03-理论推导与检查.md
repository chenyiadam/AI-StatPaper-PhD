# 03 · 理论推导与检查（P08–P12）

> 配套：[checklists/C2-理论检查清单.md](../checklists/C2-理论检查清单.md)、
> [skills/stat-theory-check](../skills/stat-theory-check/SKILL.md)。
> 本项目对 AI 理论能力的**立场声明**：
> 1. AI 是"证明审查员"和"技术工具检索员"，不是"定理发明人"。定理的核心想法（分解策略、
>    关键不等式、假设的取舍）必须由作者提出并负责。
> 2. AI 生成的证明**默认有跳步与幻觉引用**，逐行审查（P10）是必经工序，不是可选项。
> 3. 真正可靠的工作流是"作者手推骨架 → AI 填技术细节 → AI 逐行攻击 → 人工裁决"。

## P08 · 定理体系设计

**使用时机**：方法定型后、动笔证明前。把"我大概能证出什么"变成完整的定理-引理依赖图。
**前置输入**：目标函数、候选假设、期望得到的结论形态。
**核验点**：C2-B4 依赖图无环；C2-D1 定理对象与目标函数一致。

```text
你是统计渐近理论专家。基于我的方法草稿，帮我设计论文的定理体系
（theorem landscape）。你的任务是规划"要证哪些结果、按什么顺序、
每步的技术瓶颈在哪"，不是替我证明。

【方法草稿】{{目标函数 + 算法一句话}}
【候选假设】{{我打算假设的条件，如次高斯设计、稀疏度 s、损失光滑性}}
【期望结论】{{如：||估计误差|| 的依概率界；sqrt(n)-渐近正态以支撑推断}}

输出：
1. 主定理草案（Theorem 1）：按统计论文规范陈述——
   "Assume [逐条]. If [λ 的阶], then [以概率 ≥ 1-δ / 依分布], [结论含速率]."
   每个量都定义；Big-O 写全依赖参数。
2. 需要的中间结果清单（引理/命题），每条标注：
   - 内容一句话
   - 依赖关系（依赖哪些其他引理/假设）
   - 已知程度：[教科书现成（给出处方向）| 文献可借（改条件）| 需自证（难度）]
   - 风险：最可能卡住的点
3. 定理依赖图（文字版 DAG）：Lemma A → Lemma B → Theorem 1 → Corollary 1…
4. 与文献速率的定位：我的速率若为 X，已知下界方向是什么（说明这是
   你的领域知识，需我核实 [待核验]）。
5. "假设-结论"匹配自检：逐条假设回答"它被用在证明的哪一步？"
   说不出使用位置的假设，要么删掉要么标记为可疑。

约束：若我的期望结论在现有技术下不可达，明确说不可达，并给出可达的
替代结论形态。
```

## P09 · 证明骨架生成（作者主导版）

**使用时机**：P08 完成后，逐个定理使用。
**前置输入**：P08 的定理陈述与引理清单；你自己的证明路线想法（哪怕是直觉）。
**核验点**：AI 会引入未声明的假设与幻觉引理——所有 "by Lemma/By [Ref]" 进 C2-B1/C14。

```text
你是证明起草助手。我给你定理陈述、引理清单和我的证明路线直觉。
按我的路线起草证明，禁止偏离路线另起炉灶；若你认为路线走不通，
先停下说明理由，等我确认再改。

【定理陈述】{{贴 P08 输出}}
【可用引理清单】{{逐条：Lemma A.1 内容…（只允许引用清单内的编号）}}
【我的路线直觉】{{如：先做基不等式分解，L1 误差拆估计误差+近似误差，
  正则项用 KKT 条件控制}}

起草规则：
1. 分步陈述：Step 1/2/3…每步一个断言；断言必须完整可读。
2. 每次引用引理/文献/前步结论，显式写出编号；引用清单外的任何结果
   都不允许——需要新引理就输出"⚠ 需要补充引理：内容草案"。
3. 所有不等式给出方向与成立理由（三角不等式/Minkowski/Holder/…），
   禁止"显然"。
4. 处理概率界时：区分"在事件 E 上"与"P(E^c) 控制"两部分，分别给界。
5. 常数编号 C1, C2, …从头到尾递增，不重用。
6. 证明结束给出 □，并附"跳步清单"：你自己认为尚未完全展开的地方，
   逐条列出（我会决定展开或建引理）。
7. 输出为 LaTeX（amsthm 环境 proof 内）。
```

## P10 · 证明逐行审查（AI 当审稿人攻击证明）

**使用时机**：每个证明初稿完成后，必跑；C2 清单的自动化执行。
**前置输入**：证明全文 + 该证明允许引用的引理清单全文。
**核验点**：AI 审查意见也要人工裁决——AI 会把正确步骤报成错误（漏报与误报都存在）。
**工作方式**：建议同一证明跑 2 个不同模型独立审查，意见取并集再人工裁决。

```text
你是一位以严苛著称的统计理论审稿人（Referee #2 人格）。你的唯一任务：
攻击下面这个证明。你不负责欣赏它，不负责润色，只找漏洞。

【允许引用的材料】{{引理清单/文献列表全文，除此之外一律视为不可引用}}
【待审查证明】{{粘贴}}

按以下六类逐行扫描，输出编号问题清单（每条：位置/问题类别/具体
理由/建议修法/严重度 高中低）：

【Q1 幻觉引用】证明中每个 "by Lemma X / by [Ref]" 是否在允许材料中？
  条件是否真的满足？（逐条核对，一条不漏）
【Q2 跳步】任何"显然/易得/it follows"或隐含未证断言；不等式方向、
  常数吸收、求和次序交换有没有给出理由？
【Q3 收敛模式】O_p/o_p 运算是否合法；依概率/a.s./L^q 是否混用；
  极限与求和/积分/期望交换是否有控制条件支撑。
【Q4 维数与常数】p 依赖 n 时是否被当作常数；C 的一致性；δ 依赖关系。
【Q5 事件完整性】好事件上的界与坏事件概率控制是否都有；两个界合并
  时概率项是否算对（union bound 系数）。
【Q6 条件-结论匹配】定理陈述里的每条假设在证明中是否真的被用到；
  证明里是否偷偷用了陈述外的条件（这是最严重的）。

输出末尾给出：你认为证明整体成立性判断：成立（小修）/ 有实质漏洞
（列出）/ 路线不可行。注意：不确定就说不确定，禁止为了好看而放行。
```

## P11 · 正则条件检查（假设的强弱与可验证性）

**使用时机**：假设节定稿前；回应审稿人"假设太强"前。
**前置输入**：全部假设的 LaTeX 陈述 + 定理结论。
**核验点**：C2-A 组；尤其 A5 维数条件全文一致、A2 有强弱对比 Remark。

```text
你是渐近理论专家。逐条审查我论文的假设（Assumptions），按以下五维
给出评估表（每条假设一行）：

【假设列表】{{逐条粘贴}}
【定理结论】{{粘贴}}

五维评估：
1. 语义精确性：陈述是否数学上无歧义（量词、对什么一致、常数的
   依赖关系）。有歧义就给出改写建议（LaTeX）。
2. 标准性：这是该领域的标准假设吗？若标准，给出文献中的常见形式
   与出处方向 [需我核验]；若非常规，说明为什么需要。
3. 强弱定位：与最近邻文献的假设相比更弱/更强/不可比？列出可放松的
   方向（如：逐元素条件 → 行范数条件）。
4. 可验证性：真实数据场景下研究者能否检验它？给出检验思路或明确
   "不可验证，属信念性假设"。
5. 使用位置：对应证明的哪一步（我说不出的你标注"疑似冗余"）。

最后输出：
- 建议删除的假设（冗余）
- 建议放松的假设（改写为更弱形式的具体建议）
- 建议增加 Remark 讨论的假设（给出 Remark 草稿）
- 维数条件一致性检查：s log p = o(n) 这类条件在正文/附录/模拟参数
  中的取值是否一致（我提供模拟设置时）。
```

## P12 · 反例构造（攻己方定理）

**使用时机**：假设定稿后（确认假设不可再弱）；审稿回复阶段（回应"能否放松"）。
**前置输入**：候选的弱化假设形式；定理陈述。
**核验点**：反例本身要人工验证——AI 构造的反例可能不满足它声称满足的条件（双重幻觉）。

```text
你是构造反例的专家。任务：判断下面这个"假设弱化"是否可行——
即在弱化后的条件下，构造一个显式反例使定理结论失败。

【定理陈述】{{粘贴}}
【候选弱化】{{如：把逐元素次高斯放宽为仅二阶矩存在}}

任务：
1. 若你认为可构造反例：给出完整构造——
   - 数据分布/序列的显式定义（写出所有参数）
   - 逐条验证反例满足弱化后的所有假设（这一步要完整，不许跳）
   - 证明定理结论在此反例上失效（算出矛盾的具体量）
   - 反例的直觉：它踩中了原证明依赖的哪个关键不等式
2. 若你认为不可构造：给出你的理由（哪些结构性质仍由弱条件保证），
   并指出这属于"你的判断"还是"可引用的一般定理" [需核验]。
3. 无论哪种结果，说明对论文写作的影响：
   - 反例成立 → 在假设的 Remark 中加入"该条件不可去"并引用本反例
     （可放附录，这是加分项不是丢脸项）
   - 反例不成立 → 假设可以放松，回到 P11 改写。

警告：你的反例构造历史错误率不低。所有"验证反例满足假设"的步骤
我都将逐步重算，发现任何一步是糊弄的，整条反例作废。
```
