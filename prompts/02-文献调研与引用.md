## P04 · 文献检索策略生成

**使用时机**：开题后第一周；换综述角度时重跑。
**前置输入**：P01 的问题陈述；你所在数据库权限范围。
**核验点**：AI 建议的关键词可能偏离该子领域行话，用综述里的真实术语校准。

```text
你是学术检索专家，熟悉 Web of Science / Scopus / arXiv / Semantic Scholar /
Google Scholar 的检索语法。基于我的问题陈述，设计一份系统的检索方案。

【问题陈述】{{粘贴}}

输出：
1. 概念分解：把问题拆成 2-3 个概念块（如：{高维推断} × {协变量偏移} × {置信区间}）。
2. 每块的关键词矩阵：
   - 行话（该子领域惯用词，含同义/旧称/缩写，如 lasso / penalized regression /
     variable selection）
   - 排除词（避免噪声，如排除 pure ML application）
3. 每个数据库的具体检索式（给出可直接粘贴的布尔串，含截词符与字段限定）。
4. 检索执行计划：
   - 滚雪球：从 2-3 篇锚点文献向前（引它的）向后（它引的）各扩展几层
   - 时间窗与筛选标准（年份、期刊层级、引文阈值）
   - 停止规则（连续 N 篇新检索无相关即停）
5. 综述笔记模板：告诉我精读时每篇该记什么字段（见 P05）。

注意：检索式要可复现——我之后要按 PRISMA 风格记录"检索式→命中数→筛选后数"。
```

## P05 · 文献精读笔记（单篇结构化提取）

**使用时机**：每篇锚点文献精读时；配 Zotero 笔记栏。
**前置输入**：文献 PDF（或粘贴正文）；你当前的问题陈述（帮助聚焦）。
**核验点**：AI 提取的"定理内容"必须回原文核对编号与条件——这是 C6-L3 的 3.5 项。

```text
你是统计文献精读助手。我给你一篇论文全文与我的研究问题，产出一份
结构化笔记。所有内容标注出处页码/章节号；你不确定的地方显式写
[待核对]，禁止补全式幻觉。

【我的研究问题】{{一句话}}
【论文】{{粘贴全文或分节粘贴}}

输出模板（字段缺失写 N/A）：
- 一句话定位：这篇论文在解决什么统计问题
- 科学问题张力：理论与实际需求的矛盾点是什么
- 模型设定：DGP、参数空间、维数关系 (n, p, s)
- 核心方法：估计量/检验统计量的定义（抄下关键公式并注明式号）
- 关键定理：逐条列出——编号 | 假设（逐条抄） | 结论（含速率）
  | 我的研究问题视角下的用途
- 证明技术：用了什么工具链（如：KKT 条件+基不等式+逐块论证；
  经验过程；Le Cam 两点法）——这决定我能不能借用
- 实验设计：模拟场景网格、指标、真实数据集
- 局限（作者自己说的）：逐条抄
- 局限（我发现的）：结构与作者结论的落差
- 与我的问题的差分：whereas [该文假设/结果], our approach ...
- 可引用点：哪句话的观点值得被我引用，引在什么位置（核对后填）
```

## P06 · 文献综述段落写作（按脉络组织）

**使用时机**：笔记积累 ≥ 10 篇后，写 Introduction 的 Related work。
**前置输入**：多份 P05 笔记；目标期刊一篇同方向论文的 Related work 节（做风格锚点）。
**核验点**：C4-B3 差分句式；C6 全部引用；禁止"文献流水账"。

```text
你是统计论文写作教练。基于我提供的文献笔记（结构化的），写 Related
work 段落初稿。

【风格锚点】{{粘贴目标期刊同方向论文的 Related work 一段，作为语气与
密度参照}}
【文献笔记】{{粘贴 P05 的多份笔记（可压缩）}}
【我的问题与差分】{{一句话}}

要求：
1. 组织方式 = 按方法脉络，不按时间流水账；每条脉络一段。
2. 每段结构：脉络的演化逻辑（1-2 句）→ 代表工作与其贡献（2-4 篇，
   用作者-年份）→ 该脉络的隐含假设/未解决问题（1 句）→ 与本文差分
   （1 句，whereas/in contrast 句式）。
3. 密度控制：每段 3-8 篇引用；总长 ≤ 1 页。
4. 差分句库（不得三连用同一句式）：whereas / in contrast /
   differs from / complementing these / extends ... to ...
5. 输出为 LaTeX（\citep/\citet 正确区分：叙述性引用用 \citet）。
6. 引用 key 用占位符 [KEY-作者年份关键词]，我核验后替换为真实 bibkey。
7. 末尾自查清单：每条引用是否承担了明确论证功能（背景/对比/缺口/
   方法来源）？纯装饰性引用删去。
```

## P07 · 三层引用核验（AI 辅助 + 人工裁决）

**使用时机**：任何要进入正文/参考文献库的引用，逐条执行。
**前置输入**：待核验的引用条目（题名/作者/年份/DOI）+ 你声称它支持的论点原文。
**核验点**：这就是核验本身；AI 通过 ≠ 通过，AI 只做初筛与定位，L1-L3 的人工动作见 C6。
**背景**：借鉴 Open Academic Paper Gen 的三层核验流水线与 PaperQA2 的"证据定位"思想。

```text
你是引用核验助手。对下面这条"引用-论点"配对，做三层核验初筛，
并明确指出每层你需要我人工确认什么。

【待核验引用】{{题名/作者/年份/期刊/DOI/卷期页，AI 给的照抄}}
【我声称该文献支持的论点】{{粘贴我正文中的句子}}

第一层·存在性（L1）：
- 列出该条目内部的自相矛盾信号（DOI 格式错、卷期页与年份不符、
  作者名与领域不匹配、期刊名与主题错位等）。
- 生成我应执行的精确验证动作清单：在 doi.org 输什么、在 Crossref API
  查什么（给出可直接访问的 api.crossref.org/works/DOI 查询链接）、
  在 Google Scholar 搜什么。
- 输出判定：形式可疑/形式正常（注明：这只是初筛）。

第二层·字段一致性（L2）：
- 生成对照表：该条目每个字段 → 我应从出版商页面核对什么。
- 给出规范的 BibTeX 条目模板（占位），标注哪些字段必须来自出版商
  官方导出而非手打。

第三层·内容支撑（L3）：
- 根据我声称的论点，列出"打开 PDF 后我应直奔哪一节找什么形式的证据"
  （定理？数值实验？某段讨论？）。
- 给出三种常见不支撑情形的鉴别标准：
  a. 条件缺失型（原文结论有条件，我的引用弱化了条件）
  b. 强度错位型（原文数值实验结论被我写成理论结论）
  c. 张冠李戴型（结论相似但属于另一篇文献）
- 输出：我引用句子与论点的"支撑强度初判"：支撑/部分支撑/需改写/
  无法判断——并说明为什么 AI 无法最终判定。

最后：给出该条目的核验记录模板（核验日期/动作/结果/PDF 存放路径）。
```
