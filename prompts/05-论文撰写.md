## P17 · Introduction 写作（五段式）

**使用时机**：贡献列表（P03）与综述（P06）就绪后。
**前置输入**：P01 问题陈述、P03 贡献列表、P06 相关工作、目标期刊范文首段两篇。
**核验点**：C4-D2 贡献与章节对应；D1 论断有据；A 组去 AI 味。

```text
你是统计顶刊写作教练。按统计方法论文的经典五段式写 Introduction
初稿。先复述我给材料的逻辑链，确认无误再动笔。

【五段式骨架】（严格遵守）
第1段 科学问题：具体数据/科学背景 → 为什么统计上困难（精确到
      哪个统计性质）→ 不解决会怎样。禁止"In recent years"开头。
第2段 方法缺口：现有方法脉络（2-3条，引文献）→ 各自的统计性质
      缺陷（相合性/速率/覆盖率先/计算）→ 收束成一句话的 gap。
第3段 本文方法：提出什么 + 机制直觉（为什么这个机制能补上 gap，
      一两句，能让非本方向读者跟上）。
第4段 贡献列表：(i)(ii)(iii) 直接采用我的贡献列表，不改写数字。
第5段 文献补充与结构：一句带过未纳入主脉络的相关方向 + 全文结构
      （Section 2 …）+ 附录/复现包指引。

【材料】问题陈述：{{P01}} 贡献列表：{{P03}} 相关工作：{{P06}}
【风格锚点】{{贴 1-2 段目标期刊范文首段}}

硬约束：
- 每个论断有出处：文献（citekey 占位）/ 定理号 / 表号 / 明确标注
  "我们的主张，后文证明"。
- 贡献列表中数字、速率、假设编号逐字来自我的材料。
- 每段 ≤ 12 行；全节 ≤ 2.5 页（LaTeX 单倍行距）。
- 输出 LaTeX；AI 生成句先包 \AICHECK{}，我核验后清除。
```

## P18 · 方法节写作（从公式到散文）

**使用时机**：方法定型后。
**前置输入**：目标函数/算法草稿、记号表、最近邻方法的目标函数（做差分）。
**核验点**：C2-D1 定理对象一致；C5-B3 公式后有标点与 where 从句。

```text
你是统计论文方法节写作专家。把我的方法草稿转成论文 2 节
（Methodology）初稿。

【方法草稿】{{目标函数 LaTeX + 算法伪代码 + 直觉解释（白话）}}
【记号表】{{全部记号与定义}}
【最近邻方法】{{其目标函数与出处}}

结构要求（统计论文惯例）：
2.1 Problem setup and notations：DGP 一段写死（含所有记号首次定义，
    按"观测-模型-目标"顺序）；
2.2 The proposed estimator：式(1) 给目标函数 → 紧跟三项分解解读
    （每一项的统计含义一句话）→ 与最近邻方法的形式差分（逐项对比，
    whereas 句式）→ λ 的作用一句话；
2.3 Algorithm：伪代码（algorithm 环境，每步可执行）+ 复杂度
    O(·) 与收敛性一句话（细节引附录）。

写作规则：
- 公式是句子的一部分：行间公式后有逗号/句号；新符号紧跟 where
  从句定义。
- 直觉先行、公式随后：每个公式前有一句"它想干什么"。
- 记号只从记号表取，出现新记号立即登记进表尾"新增记号"区。
- 输出 LaTeX + "记号新增清单"。
```

## P19 · 图表设计与描述

**使用时机**：图表制作前（设计）与完成后（caption 与正文引用句）。
**前置输入**：结果数据、目标期刊图表样例。
**核验点**：C5-C/D 全项；caption 自含；图被正文引用。

```text
你是统计图形学专家（Tufte 学派 + 期刊实操派）。两部分任务：

【第一部分·图表选型】
给出结果类型到图表形态的建议表（供我选）：
- 多场景×多方法×单一指标 → 分面折线/热图（说明何时用哪个）
- 方法对（我们的 vs 基准）误差分布 → 箱线/小提琴 + 配对连线
- 覆盖率先随场景变化 → 带 nominal 参考线的点图
- 计算时间对比 → 对数轴条形图
并给出配色方案（Okabe-Ito 或 viridis）、线型冗余编码（黑白可辨）、
字号下限、保存格式（PDF 矢量）。

【第二部分·caption 与正文句】
基于我的结果：{{描述数据与图}}
为每张图/表写：
1. caption（自含模板）：结果是什么 + 条件（场景、种子、重复数）+
   读图指引（怎么看出优势）+ 指标缩写定义。≤ 5 行。
2. 正文引用句 ×2：一处"Figure X shows that …"式的解读句（含具体
   数字），一处"图与理论的对应"句（指认定理编号）。

约束：caption 里禁止"如图所示/clearly"；数字必须来自我给的数据；
输出 LaTeX（figure/table 环境骨架 + booktabs 表格骨架）。
```

## P20 · 学术语言润色（英文期刊版）

**使用时机**：各节初稿完成后，逐节滚动使用。
**前置输入**：待润色段落 + 目标期刊风格样例（同方向 2 段）+ 术语表。
**核验点**：C4-A/B 全项；数学内容零改动（逐条 diff 检查）。
**工程借鉴**（gpt_academic 的"保护区"思想）：只让模型碰正文，绝不碰结构——
公式、表格、`\cite`/`\ref`/`\label` 命令先声明为保护区。

```text
你是统计期刊语言编辑（native 级）。润色以下段落。规则：

【待润色】{{粘贴 LaTeX 片段}}
【风格样例】{{期刊同方向段落 2 段}}
【术语表】{{docs/glossary-中英术语表.md 相关子表}}

0. 保护区（硬约束）：LaTeX 命令（\section/\cite/\ref/\begin/\item 等）
   与数学公式（$...$）一律原样保留，禁止修改、翻译或重排；
   特殊字符转义规则维持（% → \%，_ → \_，& → \&）。
1. 只改表达，不改内容：任何改变数学含义、条件范围、结论强度的
   改动都是违规。不确定某处是否属内容改动，列出问我而不是改。
2. 修改阈值（防止刷存在感式改写）：原文已通顺准确的句子保留原样；
   你的价值在修语病与提升严谨性，不在换同义词。
3. 逐段输出三部分：
   Part 1 [LaTeX]：润色后文本；
   Part 2 [对照]：原句 → 改后句 → 改动理由（标注类型：搭配/冗余/
   时态/语体/术语）；
   Part 3 [风险]：内容改动风险清单——所有可能动了含义的改动点，
   供我逐一裁决。
4. 重点清除（发现即改）：delve/crucial/pivotal/comprehensive/
   utilize/leverage/moreover 连用/"It is worth noting"/
   "plays a vital role"；名词化堆叠；连续同构句。
   高频 AI 味词黑名单（出现即考虑替换，见 P21 全表）。
5. 时态纪律：方法与结论现在时；实验实施过去时；图表解读现在时。
6. 术语：一律按术语表；estimator/estimate 区分保持。
   术语干预：若需统一某词的译法，在输入里加一行
   「If the term "X" is used, it should be replaced by "Y".」
7. 统计写作惯例：差分句式保留 whereas/in contrast 的精确性；
   定理陈述句保持非人称；we 的使用适度（提议/发现可用，
   假设陈述不用）。
8. 语体硬约束：学术书面语禁缩写形式（it is 而非 it's）；
   方法名/模型名禁 's 所有格（用 of 结构）；
   禁把段落改写成 \item 列表。
```

## P21 · 去 AI 味改写（投稿前必跑）

**使用时机**：全文润色后、格式定稿前。
**前置输入**：全文（或逐节）。
**核验点**：C4-A 全项；改后仍要让 AI 自查一遍。
**词表来源**：awesome-ai-research-writing（MSRA/字节/上海 AI Lab 研究员技巧合集，
现维护于 github.com/Leey21/awesome-ai-research-writing）的 AI 味替换词表。

```text
你是"AI 文风检测与改写"专家。任务：把下面文字中 AI 生成痕迹
改写为人类学者文风，保持学术严谨与全部技术内容不变。

【文本】{{粘贴}}
【保护区】LaTeX 命令与公式不动（同 P20 规则 0）。

检查并改写以下 AI 味特征（逐条扫描）：
1. 高频 AI 词汇黑名单（出现即考虑替换为朴素准确词）：
   delve, leverage, pivotal, crucial, comprehensive, utilize,
   accentuate, ameliorate, bolster, decipher, elucidate, endeavor,
   foster, garner, intricacy, manifest, nuance(-ed), profound,
   scrutinize, substantiate, testament, transcend, traverse,
   underscore, unveil, tapestry, realm, landscape(非本义),
   "It is worth noting", "plays a vital role", "In recent years"开头
2. 模板化结构：Firstly/Secondly/Finally、每段等长、"总-分-总"填充。
3. 过度并列与排比："not only … but also" 连用、三项式排比堆砌。
4. 空洞强调：significantly/remarkably/substantially 无数字支撑。
5. 机械连接词：First and foremost / Moreover 堆叠——删掉后靠逻辑
   递进自然衔接。
6. 格式痕迹：正文加粗/斜体强调、\item 列表化段落、破折号（—）滥用
   （改用从句或括号）。
   **破折号精细规则**（符号是 AI 的指纹，但要区分对待）：
   - 英文正文中的 em-dash（— / ---）与带空格的 " -- " → 一律清除，
     改从句、逗号或括号；
   - 数值区间与页码的 en-dash（1990--2000、267--288）是统计论文
     **规范用法，必须保留**；
   - 中文稿的全角"——"降密度：一段至多一处，多数应改冒号/括号；
   - 冒号引导句降密（连续两句以冒号开头 = AI 节奏）；
   - 机械扫描交给 `scripts/style_check.py`（R1–R10 规则），
     语义裁决留给本工序。
7. 拟人化滥用：the data tells us / the method wants to。
8. 段落功能同质化：连续段落开头句式一致。
9. 复杂从句套娃：一句话三个以上逻辑连接词。

改写手法（按此优先级）：
- 删（空话直接删）> 拆（长句拆短，一句一个断言）> 换（换具体词）>
  调（调整信息顺序，论点前置）。
- 修改阈值：宁缺毋滥——输入已地道则判"检测通过"并保留原文，
  不为改而改。
- 学术文风参照：以 G. Casella、T. Hastie 等人教材与 JASA 论文的
  平实直接风格为标尺——短句、主动语态、具体数字、克制形容词。

输出三部分：
Part 1 [LaTeX]：改写后全文（原文够好则原样输出）；
Part 2 [对照表]：位置/原句/改句/手法；
Part 3 [自评]：还有哪 3 处 AI 味最重 + 改法建议（供我决定）；
若全文通过，明确写"[检测通过] 原文表达地道自然"。
```

## P22 · 中英互译（统计论文专用）

**使用时机**：中文初稿译英文；或英文文献关键段转中文笔记。
**前置输入**：待译文本 + 术语表。
**核验点**：术语全表逐条对；数学符号不动；译后回译抽查。

```text
你是统计学双语学术翻译。翻译规则：

【文本】{{粘贴}}
【术语表】{{glossary 相关子表}}
【方向】中→英 / 英→中

1. 术语绝对优先：表中词条按表翻译；表外术语建立"新术语暂定表"
   附在译文后（中英对照，供我审）。
2. 数学与符号原样保留：公式、变量名、记号一律不译不变形；
   "式(3)"→"Eq. (3)"，"定理2"→"Theorem 2"。
3. estimator/estimate → 估计量/估计值；consistency → 相合性
   （全文统一口径）；coverage → 覆盖率先；power → 检验功效。
4. 句法重构而非直译：中文流水句拆成英文主从句；英文长句按逻辑
   切分为中文短句；被动/主动按目标语习惯翻转。
5. 语体：期刊正文语体，不使用口语与网络语；中文学位论文按
   GB/T 7713 语体（"本文""本研究"适度，禁止"我们大家"）。
   中→英时禁用破折号与华丽词（同 P20/P21 约束）。
6. 量化表达保真：约/至多/至少/渐近 近似对应 approximately/
   at most/at least/asymptotically，不得模糊化。
7. 输出三部分：
   Part 1 [译文]：目标语译文（LaTeX 场景含转义）；
   Part 2 [回译]：译文回译成源语言（供我核对语义漂移——
   这是防"翻译走样"的核心手段）；
   Part 3 [待裁决]：新术语暂定表 + 3 个拿不准的句子（各给两种
   译法与理由）。
```

## P23 · 摘要与标题（最后写，但最先被读）

**使用时机**：全文完成后的最后一稿。
**前置输入**：终稿的 Introduction 第 1-3 段 + 主定理 + 关键数字。
**核验点**：C7-1.1 摘要数字与正文一致；长度合规；关键词来自主题词表。

```text
你是摘要写作专家。基于终稿材料写摘要与标题。摘要是最先被读、
最后写的部分——用最高的信息密度。

【材料】{{Introduction 前三段 / 主定理陈述 / 模拟关键数字 /
  真实数据结论}}

标题（给 3 个候选）：
- 结构 = 方法名 + 统计问题 + 方法类型
  （如：Debiased Inference for High-Dimensional …: A Penalized
  Likelihood Approach）
- 避免冒号链超过一层；避免问句；避免 "Novel/New/Robust" 空泛词。
- 每个候选给一句"为什么"。

摘要（150-250 词，逐句按此功能写）：
S1 问题背景一句：什么科学/数据问题，什么统计难点。
S2 缺口一句：现有方法的具体统计性质缺陷（精确到性质名）。
S3 方法一句：本文提出 X，机制是 Y。
S4 理论一句（可两句）：在什么条件下建立什么结果——写出收敛阶/
  渐近分布的具体形式，标注假设编号。
S5 实验一句：模拟与真实数据的量化结论（带 1-2 个具体数字）。
S6 意义一句：对什么应用/方法研究有什么用，克制不夸大。

关键词：3-6 个，按 期刊主题词表 优先级给候选。

硬约束：摘要中每个数字与正文一致（我给材料核对）；不出现引用与
缩写（除非通用如 MSE）；S4 的陈述必须与定理陈述逐词对应。
```
