# 07 · 期刊风格适配（P28–P32）

> 配套：[journals/](../journals/README.md)（9 个期刊风格档案，本目录的"弹药源"）、
> [skills/stat-journal-fit](../skills/stat-journal-fit/SKILL.md)、
> `checklists/C5`、`templates/cover-letter.md`。
> 目标：把一篇**已通过 S1–S6 质检的初稿**，改造成目标期刊的"可投状态"。
> 铁律：改风格不改内容——任何改写不得改变数学含义、结论强度与数字
> （沿用 P20/P21 的三栏输出与内容改动风险清单机制）。

---

## P28 · 期刊风格剖析（生成该刊风格规则卡）

**使用时机**：选定目标期刊后第一步；换刊时重跑。
**前置输入**：目标期刊同方向论文 2–3 篇的全文（或 Introduction+方法节开头+
一个定理陈述+一张表）+ `journals/<该刊>.md` 档案。
**核验点**：规则卡必须"可对照改写"——每条规则能回答"这句该怎么变"。

```text
你是期刊风格分析师。基于我提供的期刊档案与该刊同方向论文样本，
生成一份"风格规则卡"——供后续逐段改写使用。

【期刊档案】{{粘贴 journals/<该刊>.md}}
【样本论文】{{贴 2-3 篇同方向论文的关键部分}}

输出规则卡（每条规则给出：规则名 / 惯例描述 / 从样本中摘 1 句实例 /
对本文的适用动作）：

1. 结构规则：章节组织、贡献呈现方式（列表 or 融入行文）、
   Discussion 有无及写法、证明位置（正文/附录）、篇幅感知。
2. 段落与句式规则：段均长度、开段句式（论点句/背景句）、
   差分句式偏好、第一人称使用密度、时态惯例。
3. 理论呈现规则：定理密度、假设-Remark 配套、与文献速率的
   对话方式、证明详略。
4. 实验呈现规则：表格密度与规格、场景呈现方式、数据故事化程度、
   复现材料惯例。
5. 词汇规则：该刊高频学术词（从样本统计）、该刊忌讳词
   （结合 AI 味黑名单）、拼写体系（英式/美式）。
6. 格式信号：引用样式、图表规格、定理环境编号式样。

末尾输出"本文差距表"：把我初稿的 Introduction 首段与样本论文首段
并排对比，列出 5 条最刺眼的风格差距（先给我看差距，再动手改）。
```

## P29 · 结构重排（初稿 → 该刊骨架）

**使用时机**：风格规则卡就绪后。
**前置输入**：初稿全文结构 + 目标刊档案的结构惯例节。
**核验点**：C4-D2 贡献-正文对应在重排后不断裂；定理-证明引用闭环。

```text
你是论文结构架构师。把我的初稿重排成目标期刊的结构惯例。
你的产出是"迁移计划 + 重排骨架"，不逐段改写文字。

【初稿结构】{{贴各节标题 + 每节 2 句概括 + 现有定理/表编号清单}}
【目标刊惯例】{{粘贴该刊档案"结构惯例"节 + P28 规则卡的结构部分}}

输出：
1. 差异清单：初稿结构 vs 该刊惯例，逐节列出（新增/删除/移动/
   合并/拆分），每条给理由与影响范围（哪些交叉引用会变）。
2. 迁移计划表：内容块 → 去向（正文/附录/补充材料/删除），
   附编号映射表（旧式号 → 新式号，如 Thm 3 → Thm 2, Lemma A.4 → B.2）。
3. 重排后的 LaTeX 骨架（章节树 + 每节首句占位 + 交叉引用改写清单）。
4. 断裂检查：重排后每个定理/表/式是否仍被引用、每个引用是否仍可解析
   （给出一遍 notation_check.py 的预检清单）。

约束：内容块只许移动/下沉，不许在计划阶段悄悄删除（删除是第 6 步
合规终检的裁决）。
```

## P30 · 风格改写（逐段向该刊语体迁移）

**使用时机**：结构重排完成后，逐节滚动。
**前置输入**：重排稿某节 + P28 规则卡 + 该刊样本同节段落。
**核验点**：内容零改动（三栏输出 + 风险清单）；数字与引用不动。

```text
你是该期刊的资深编辑。按风格规则卡把下面这段改写为该刊语体。
沿用本项目 P20/P21 的全部纪律（只改表达不改内容；修改阈值；
保护区=公式与 LaTeX 命令）。

【风格规则卡】{{P28 输出的相关规则}}
【样本参照】{{该刊同方向论文的同功能段落 1-2 段}}
【待改写】{{粘贴}}

执行顺序（每段都按此过一遍）：
1. 去符号 AI 味：删除正文中的破折号插入语（— / ---），改用从句、
   逗号或括号；数值区间的 en-dash（1990--2000）保留；
   冒号引导句降密；连续分号句拆分。
2. 去词汇 AI 味：过一遍黑名单（delve/leverage/pivotal/…）。
3. 对齐该刊句式：按规则卡调整开段句式、段落长度、差分句式。
4. 对齐该刊话语体系：定理-速率-最优性的表述方式按该刊惯例
   （如 AoS 的 minimax 话语 / JASA 的贡献话语 / Biometrika 的克制）。
5. 拼写体系切换（英式/美式）如有要求。

输出三部分：
Part 1 [改写稿]（LaTeX，保护区不动）；
Part 2 [对照]：原句→改句→触发的规则编号；
Part 3 [风险]：可能动了含义的改动点清单（逐条等作者裁决）。
```

## P31 · 格式与引用迁移（可编译投稿版）

**使用时机**：风格改写完成后。
**前置输入**：目标刊档案"格式硬要求"节 + 当前 LaTeX 源 + bib。
**核验点**：编译零 error；五个检查脚本全部通过；补充材料独立可编译。

```text
你是 LaTeX 投稿工程师。给我一份"格式迁移工单"，把当前源文件迁移到
目标期刊模板。

【目标刊格式要求】{{粘贴该刊档案"格式硬要求"节}}
【当前源文件清单】{{main/appendix/supplement/refs.bib + 现用文档类}}

工单按顺序输出：
1. 模板迁移：文档类/样式包替换清单；宏定义冲突排查
   （\newtheorem 编号体系、\cref 配置）；页边距字号行距。
2. 引用样式迁移：bst 切换（author-year ↔ 编号制是大工程，
   给出 \citep/\citet → \cite 的映射规则）；bib 条目字段补齐清单
   （按新样式必填字段）；引文上标/文内格式核对项。
3. 图表迁移：规格（宽度/字号/dpi）、caption 位置、三线表核对、
   编号式样（Figure 1 vs Fig. 1 vs 图 1）。
4. 前置件迁移：标题页、作者脚注、致谢、基金、数据可得性声明的
   该刊式样。
5. 匿名化（如该刊要求）：泄密点扫描清单（致谢/仓库链接/自引/路径）。
6. 验证流程：迁移后必须通过的命令清单
   （编译 ×2 + bibtex + 五个检查脚本 + supplement 独立编译）。

输出为可勾选的执行清单，每项标注"人工/可脚本"。
```

## P32 · 该刊合规终检 + Cover letter 适配

**使用时机**：迁移完成后、提交前 48 小时（与 C7 倒计时合并执行）。
**前置输入**：投稿版全文 + 该刊档案 + 期刊官网最新指南（人工核对）。
**核验点**：这是最后一道；官网最新指南 > 本档案。

```text
你是期刊合规审查员。对照目标期刊档案与 C7 清单，对投稿版做终检。
只报告，不修改。

【投稿版】{{全文/文件清单}}
【期刊档案】{{journals/<该刊>.md 全文}}
【官网指南差异】{{作者从官网核对的最新要求，与档案不同处}}

输出：
1. 档案改造清单逐项核对（该刊专属清单的每一项：通过/待办/不适用）。
2. C7 倒计时清单抽检（Day −7/−3/−1 的关键项）。
3. 风格回归检查：改写过程中是否回潮——
   a. style_check.py 是否零告警（符号与词汇 AI 味）
   b. 摘要/引言/结论的数字是否仍与正文一致
   c. 贡献-定理-表号对应是否在重排后完好
4. Cover letter 适配：按 templates/cover-letter.md 模板，产出该刊版——
   一句话贡献 + 为什么适合**该刊**（引用该刊 scope 语言与近期相关发文）
   + 无一稿多投 + AI 使用一句披露 + 建议审稿人（3–5 位，无利益冲突，
   从文献池挑方法脉络最近邻作者）。
5. 最终判定：可提交 / 阻断项清单（逐条给修复动作）。
```
