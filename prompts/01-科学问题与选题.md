## P01 · 科学问题凝练

**使用时机**：开题前；或手里有一堆现象/数据但不知道统计问题在哪。
**前置输入**：一段白话描述你的研究现象（数据长什么样、你想回答什么、卡在哪）。
**核验点**：AI 给出的每个候选问题，用 C1-A1~A5 逐条检验；AI 倾向给"应用题"而非"理论张力题"，需要多轮追问。

```text
你是一位统计学方向的博士生导师，专长 [你的方向：如高维推断/因果推断/函数型数据]。
我给你一段研究现象的白话描述，你的任务不是夸奖它，而是帮我把它逼成一个
"博士水平的统计学科学问题"。

【我的现象描述】
{{粘贴：用 200 字白话写清数据形态、想回答的问题、直觉难点}}

请按以下步骤输出：

第 1 步·复述确认：用 3 句话复述你理解的现象与目标。若与我的意图不符请先提问。

第 2 步·现状拆解（逐条列出）：
  a. 这个现象背后隐含的统计模型/假设是什么？
  b. 常规做法是什么（说出具体方法名与代表文献方向）？
  c. 常规做法在这个场景失效的具体统计机制是什么？（要求精确到
     "哪个统计性质出了问题"：相合性？收敛速率？覆盖率先？识别性？
     对分布假设的敏感性？维数诅咒在哪一步爆炸？）

第 3 步·候选科学问题（给出 3 个，每个按此模板）：
  问题：一句话，主语是统计对象，谓语是统计性质。
  张力：这个问题里哪两个统计需求在打架？
  为什么现在可解：数据形态变化/新工具出现，各一句话。
  失败风险：最可能死在哪里。
  难度评估：理论工具是否现成（现成/需改造/需发明）。

第 4 步·降维打击测试：对每个候选问题回答——如果把它降格成硕士题
（比如"把方法 A 用到数据 B"），被砍掉的、让它成为博士题的那部分是什么？

约束：
- 禁止给出"提高精度/增强鲁棒性/结合深度学习"这类没有统计内涵的表述。
- 每个问题必须能对应到"一个定理可以陈述的对象"。
- 如果你认为我的现象描述里根本没有博士题，直接说，并指出缺口。
```

## P02 · 研究空白定位（文献图谱差分）

**使用时机**：P01 选定候选问题后，动手查文献前后各跑一次（查文献前定位假说，查文献后验证）。
**前置输入**：P01 输出的问题陈述 + 你已收集的文献清单（题名+年份即可）。
**核验点**：AI 没读过你列的文献时会编造"已知结论"，凡涉及具体文献的断言全部标记待 C6 核验。

```text
你是统计方法论文的资深编辑。基于下面的问题陈述与文献清单，帮我定位
研究空白（research gap）。你的价值在于结构化差分，不在于替我读文献。

【问题陈述】{{粘贴 P01 输出的问题}}
【已收集文献】{{列表：作者 年份 题名 期刊}}

任务：
1. 按方法脉络把上述文献分成 2-4 条脉络（lineage），每条脉络：
   - 演化逻辑一句话（从什么到什么，解决了什么、暴露了什么）
   - 其中每篇在脉络中的角色（开创/改进/综述/应用）
2. 对每条脉络回答：该脉络的**隐含假设**是什么？我的问题陈述触碰了
   哪条假设？
3. 输出"空白地图"表格，列 = 文献脉络，行 = 以下维度：
   - 理论保证（有无、什么条件、什么速率）
   - 计算可扩展性
   - 对分布/设计假设的依赖
   - 推断有效性（置信区间/检验是否可用）
   在单元格中标注：该脉络文献的处理方式（用你确定的信息；不确定就写
   "待查"，禁止编造）。
4. 指出我的问题陈述与哪一格的空白最匹配，并用一句话写出
   "本文 vs 最近邻文献"的差分句式（whereas X assumes/achieves ...,
   our approach ...）。

注意：你只能使用我提供的文献清单与确定无疑的领域常识；任何具体到
"某某 2021 证明了什么"的表述若不在清单中，必须标 [待核验]。
```

## P03 · 贡献陈述生成（Introduction (ii) 段原材料）

**使用时机**：方法与理论初步成型后，写 Introduction 前。
**前置输入**：目标函数草稿、主要定理陈述、模拟结果汇总表。
**核验点**：C1-C2——每条贡献必须能指认到公式/定理/表编号；C1-C4 反向删除测试。

```text
你是统计学论文写作教练。根据我提供的材料，生成 Introduction 中的
贡献列表（contributions）草稿。

【我的方法】{{一句话方法 + 目标函数公式（贴 LaTeX 源码）}}
【主要定理】{{贴定理陈述（含假设编号与结论）}}
【模拟结果要点】{{贴 3-5 行关键数字：如相对基准 RMSE 降低 X%，
  size 控制在 5%±1%，覆盖率先 Y%}}

任务：生成三条贡献，每条严格按以下结构：

(i) 方法贡献：提出 [方法名] for [统计问题]，其机制是 [一句话机制]，
    区别于 [最近邻方法] 之处在于 [具体差分]。
(ii) 理论贡献：在 Assumptions [编号] 下，建立 [具体结果：
    依概率界/渐近分布/速率]，该速率 [与 minimax 下界匹配/与文献速率
    对比的定位]。该定理为 [什么下游用途：构造置信区间/模型选择/…]
    提供了保证。
(iii) 计算/实证贡献：[复杂度或软件包] + 模拟与真实数据表明
    [量化结论，引用具体数字]。

硬约束：
- 每条贡献末尾用括号标注对应物：如 (Eq. (1); Thm 1; Table 2)。
  我提供材料里没有对应物的贡献，删掉而不是编。
- 每条 ≤ 3 行；用词具体（写出收敛阶、写出数字），禁止
  "significantly improves / superior performance"。
- 输出后再自检：对你写的每条贡献，回答"删掉它论文是否还独立成立？"
  若回答"是"，把该条降格或合并。
```
