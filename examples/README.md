# examples · 最小走通样例

本目录用一个**玩具主题**演示流水线各环节的真实输入输出形态——
让你在 15 分钟内看懂"用对了"是什么样子，再回到自己的论文里照做。

- [demo-最小走通.md](demo-最小走通.md)：主题
  *"重尾误差下高维线性回归的稳健推断"*——从白话冲动到投稿包的
  每阶段样例输出：问题陈述、定理审查报告、引用核验卡、
  模拟数字-单元格对照表、审稿意见聚合、AI 披露段落。

**为什么用玩具主题**：真实论文的核心想法是你的品味问题，
样例的价值在于展示**形态与纪律**——每个阶段"交付物长什么样、
门禁怎么判、AI 的输出怎么被裁决"。请把注意力放在流程上，
不要引用样例中的技术内容（它们是演示用的简化版本）。
